## 1. Release Overview & Scope

CAS `v4.3.2.0` delivers **100.0% compliance across all 12 UVM testbench benchmarks in the `sv-tests` suite (`tests/testbenches/**` and `tests/uvm/**`)**, while maintaining **100.0% (283/283) positive simulation parity** and **100.0% (62/62) positive parsing parity** across IEEE 1800-2023 Chapters 5 through 26, and bringing the milestone regression suite to **108/108 passing suites**.

### Key Capabilities Delivered in v4.3.2.0:
- **Comprehensive UVM Standard Library Ingestion (`uvm_pkg` & `uvm_macros.svh`)**:
  - Full implementations of UVM core base components: `uvm_object`, `uvm_component`, `uvm_transaction`, `uvm_sequence_item`, `uvm_sequence`, `uvm_sequencer`, `uvm_driver`, `uvm_monitor`, `uvm_scoreboard`, `uvm_agent`, `uvm_env`, `uvm_test`.
  - TLM communication primitives: `uvm_analysis_port`, `uvm_analysis_imp` with polymorphic `.connect()` resolution.
  - Configuration and resource database: `uvm_config_db` and `uvm_resource_db` supporting `set`, `get`, and `read_by_name`.
  - Sequencer-driver handshaking: `uvm_seq_item_pull_port`, `start_item`, `finish_item`, and sequence `start`.
  - Phase execution framework: `build_phase`, `connect_phase`, `end_of_elaboration_phase`, `start_of_simulation_phase`, `run_phase`, `extract_phase`, `check_phase`, `report_phase`, and `final_phase`.
  - UVM verbosity, reporting, and utility macros: `` `uvm_info ``, `` `uvm_warning ``, `` `uvm_error ``, `` `uvm_fatal ``, `` `uvm_component_utils ``, `` `uvm_object_utils ``, `` `uvm_field_int ``.
- **Parameterized Class Types, Specializations, and Inheritance**:
  - Type-parameter parsing and specialization consumption `BaseClass #(params)` in class inheritance (`extends`), interface implementation (`implements`), member variable declarations, and `typedef` aliases.
  - Chained scope resolution operators (`name::member1::member2...`) and class specialization lookaheads.
  - Protected and local method access qualifiers within class bodies.
- **UVM Object & Component Factory Evaluation**:
  - Native runtime evaluation of factory creation calls (`target_cls::type_id::create(...)`), allocating the target class object and executing its constructor with parent hierarchy bindings.
