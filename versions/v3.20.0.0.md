# Release v3.20.0.0: Parameterized Functional Coverage & Event Sampling (IEEE Std 1800-2023 §19.4 & §19.8, Covergroup Formal 'ref' & 'input' Arguments, Clock/Event Sampling Triggers '@(event_expr)', 'option.per_instance = 1', Dynamic Coverage Calculation via 'get_inst_coverage()', and Context Diagnostic '[CAS-DTINPCIL]')

## 1. Overview & Milestone Scope
This release delivers **v3.20.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **50.0%** and implementing full IEEE Std 1800-2023 compliance for:
- **§19.4 & §19.8 (Advanced Functional Coverage: Parameterized Covergroups & Automatic Event Triggers)**:
  - **Parameterized Covergroup Declarations (§19.4)**:
    - Declaration syntax:
      ```systemverilog
      covergroup cg_identifier ( [ port_list ] ) [ @(event_expression) ];
          [ option.per_instance = 1; ]
          { coverage_specification }
      endgroup [ : cg_identifier ]
      ```
    - Support for formal argument lists with direction modifiers:
      - `ref`: binds formal identifier by reference to variable in instantiation scope.
      - `input`: evaluates actual argument expression at instantiation time (`new()`) and binds constant value into bin ranges or coverpoint expressions.
  - **Automatic Clock & Event Sampling Triggers (§19.4 & §19.5)**:
    - Syntax: `covergroup cg(...) @(posedge clk);`, `cg(...) @(negedge clk);`, `cg(...) @(event);`.
    - Automatic registration of active covergroup instances with stratified event scheduler.
    - Automatic event trigger evaluation and sampling on clock edges (`posedge`, `negedge`, level) during the scheduler's delta cycles.
    - Time-slot edge debounce preventing duplicate firings in the same time slot (`fired_in_time_slot`).
  - **Instance Options & Dynamic Coverage Querying (§19.8)**:
    - Support for `option.per_instance = 1;` at covergroup body level and coverpoint scope.
    - Support for dynamic coverage querying method `cg_inst.get_inst_coverage()`.
    - Integration with static type casting `int'(cg_inst.get_inst_coverage())`.
  - **Dynamic Context Diagnostic Enforcement (`[CAS-DTINPCIL]`)**:
    - Rejection of covergroup handles or method calls (`.sample()`, `.get_coverage()`, `.get_inst_coverage()`) inside non-procedural contexts such as continuous assignments (`assign`) and `$monitor` with diagnostic `[CAS-DTINPCIL]`.

## 2. Technical Architecture & Implementation Mechanics

### A. Frontend Lexer & AST Nodes
- **Lexer (`CAS/include/frontend/lexer.hpp`, `CAS/src/frontend/lexer.cpp`)**:
  - Added token type `TokenType::TOKEN_REF` recognizing reserved keyword `"ref"`.
- **AST Nodes (`CAS/include/frontend/ast_module.hpp`, `CAS/include/common/coverage_types.hpp`)**:
  - In `CovergroupNode`:
    - Added `std::vector<PortNode> arguments;` holding formal port definitions.
    - Added `bool has_event_trigger;`, `EdgeType event_edge;`, `std::string event_signal;`.
    - Added `bool per_instance;`.
  - In `CovergroupInstance`:
    - Added `bool has_event_trigger;`, `EdgeType clock_edge;`, `size_t clock_net_id;`, `bool fired_in_time_slot;`, `bool per_instance;`.

### B. Parser Implementation (`CAS/src/frontend/parser_module.cpp`)
- **Covergroup Header & Argument Parsing**:
  - Replaced token skipping in `parse_covergroup()` with full formal argument list parser supporting `ref`, `input`, type (`logic [msb:lsb]`, `int`, etc.), parameter names, and optional default values.
  - Parsed event triggers `@(posedge clk)`, `@(negedge clk)`, `@(clk)`.
  - Parsed `option.per_instance = 1;` at both covergroup body level and inside individual coverpoints.
  - Added support for covergroup declarations inside package scopes (`parse_package()`).

### C. Kernel Engine & Argument Substitution (`CAS/include/engine.hpp`, `CAS/src/kernel/evaluator.cpp`)
- **Argument Binding & AST Transformation**:
  - In `Engine::allocate_covergroup_instance`:
    - Accepts actual arguments `actual_args` and `eval_expr` callback from `new(args...)`.
    - Formal `ref` arguments map to actual AST expressions.
    - Formal `input` arguments evaluate at instantiation time to 64-bit constants.
    - Coverpoints and bin ranges are cloned with recursive formal identifier substitution.
    - Event-triggered instances resolve the clock net ID in the instantiation scope and register into `engine.event_triggered_covergroups`.

### D. Stratified Scheduler Event Sampling (`CAS/include/kernel/scheduler.hpp`, `CAS/src/kernel/scheduler.cpp`)
- **Automatic Event Triggered Sampling**:
  - Added `StratifiedScheduler::evaluate_covergroup_events()` executed in each delta cycle alongside sequential and clocking block evaluation.
  - Detected transitions on `inst->clock_net_id` (`is_posedge()`, `is_negedge()`, level `modified`).
  - Evaluated target expressions and bin ranges using `inst->sample()`.
  - Debounced sampling with `inst->fired_in_time_slot`, cleared at the beginning of each simulation time slot.
