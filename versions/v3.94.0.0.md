## 1. Overview & Architectural Scope

CAS `v3.94.0.0` delivers standard compliance for module-scope dynamic array lifecycle management and width-based hexadecimal formatting:
- **IEEE Std 1800-2023 §7.5 Dynamic Arrays**:
  - Full hierarchical resolution of module-scope dynamic arrays from within procedural processes (`top.dyn_mod` accessible across nested blocks).
  - Complete support for dynamic array allocation (`dyn = new[N]`), resizing (`dyn = new[M]`), element assignment/lookup (`dyn[i]`), property querying (`.size` and `.size()`), and array deallocation (`.delete` and `.delete()`).
  - Added upward scope walking across queue and dynamic array registry lookup maps.
- **IEEE Std 1800-2023 §21.2.1.2 Hexadecimal Width Zero-Padding**:
  - `%h` / `%x` and `%H` / `%X` format specifiers pad packed vectors with leading zeros up to $\lceil \text{width} / 4 \rceil$ hexadecimal digits (e.g., `8'h00` formats as `"00"`, `8'h0f` as `"0f"`).
  - Explicit zero-width specifiers (`%0h` / `%0H`) remain unpadded (e.g., `8'h0f` formats as `"f"`), preserving full backwards compatibility across all existing regression suites.
  - Aligned `$display`, `$monitor`, and severity tasks with `$sformatf` formatting semantics.
- **Regression Suite `v3_94_0_0_dynamic_arrays_and_hex_pad`**:
  - End-to-end verification of module-scope dynamic array lifecycle and hex zero-padding, achieving 100% golden parity across both CAS and Verilator.
