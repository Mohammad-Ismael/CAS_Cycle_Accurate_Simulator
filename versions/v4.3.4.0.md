## 1. Release Overview & Scope

CAS `v4.3.4.0` expands standard elaboration and verification support across IEEE Std 1800-2023 constraint declarations, pattern matching `case ... inside`, bare signed/unsigned function and task formal arguments, and advanced class elaboration syntax. Chapter 18 (Constrained Randomization) positive tests reach **100.0% elaboration pass rate (119/119)**, and the regression test suite advances to **110/110 passing milestone suites**.

### Key Capabilities Delivered in v4.3.4.0:
- **Comprehensive Constraint Block Elaboration (IEEE Std 1800-2023 §18.5)**:
  - Lexer and parser support for constraint keywords: `dist`, `solve`, `before`, `soft`, `matches`, and weight operators (`:=`, `:/`).
  - Distribution constraints: `dist { [low:high] := weight, [low:high] :/ weight, val := weight }`.
  - Ordering constraints: `solve identifier before identifier;`.
  - Soft constraint modifiers: `soft expr;` and `disable soft expr;`.
  - Implication constraints: `expr -> { ... }` and `expr -> expr;`.
  - Unique constraints: `unique { list_of_identifiers };`.
  - Constraint loops and conditionals: `foreach ( arr[i] ) { ... }` and `if (cond) { ... } else { ... }`.
  - Prototypes and out-of-block definitions: `constraint c;`, `extern constraint c;`, `pure constraint c;`, and `constraint Class::c { ... }` at compilation unit, module, and package scopes.
  - Inline constraints with arguments: `randomize() with (x) { ... }`.
- **Pattern Matching `case ... inside` Evaluation (IEEE Std 1800-2023 §12.5.4)**:
  - Extended parser to accept `case (expr) inside ... endcase`, `casex (...) inside`, and `casez (...) inside`.
  - Support for multi-value lists and range bounds in case items: `1, 3, 5: stmt;` and `[10:20]: stmt;`.
  - Real-time evaluation in `evaluator.cpp` matching input values against discrete set items and closed intervals `[lo:hi]`.
- **Bare `unsigned` and `signed` Formal Arguments (IEEE Std 1800-2023 §6.7)**:
  - Corrected resolution of bare signedness modifiers in function and task argument lists (`input unsigned s, input unsigned d`).
  - Strict compliance with standard 1-bit default logic sizing when integer type keyword is omitted, ensuring 100% golden parity with VCS and Verilator.
- **Advanced Class Elaboration & Constructors (IEEE Std 1800-2023 §8.25, §8.26)**:
  - Typed constructor calls: `Class::new` and `Class::new(args)`.
  - Parameterized base class extension: `class Derived extends Base #(params)`.
  - Direct base class constructor parameter passing: `extends Base(args)`.
  - Built-in `process` class registration in global/compilation-unit symbol tables.
- **Procedural Statements & Variable Modifiers (IEEE Std 1800-2023 §6.21, §9.6.2)**:
  - `disable <block_label>` statement in procedural task and function bodies.
  - `automatic` variable declarations within procedural statement blocks (`automatic int val = ...;`).
