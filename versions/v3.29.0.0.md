# Release v3.29.0.0: Specify Blocks, Parallel & Conditional Module Path Delays, Inertial Time-Wheel Scheduling, and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §32)

## 1. Overview & Milestone Scope
This release delivers **v3.29.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **62.6%** and implementing full IEEE Std 1800-2023 compliance for:
- **§32 (Specify Blocks & Module Path Delays)**:
  - Specify block syntax: `specify ... endspecify` in module definitions.
  - Parallel module path delay declarations: `(source => destination) = delay;`.
  - Conditional state-dependent module path delay declarations: `if (condition_expression) (source => destination) = delay;`.
  - Time-unit and time-precision scaling based on `` `timescale `` preprocessor directives (e.g. `` `timescale 1ns/100ps ``).
  - High-precision delay scaling and rounding for procedural `#` delay statements and path delay values.
  - Inertial delay scheduling in the Stratified Event Scheduler: delayed propagation to destination nets, preemption/cancellation of pending updates upon new input events, and initial 4-state `'x'` value for path-delayed nets prior to first scheduled propagation.
- **Context Diagnostics & Semantic Restrictions (`[CAS-DTINPCIL]`)**:
  - Prohibits `specify` blocks inside procedural scopes (`initial`, `always`, `task`, `function`):
    ```text
    [CAS-DTINPCIL] Dynamic type in non-procedural context: 'specify' block is not permitted inside procedural scope per IEEE 1800-2023 section 32
    ```
  - Prohibits `specify` blocks inside interfaces, packages, or classes:
    ```text
    [CAS-DTINPCIL] Dynamic type in non-procedural context: 'specify' block is not permitted inside interface per IEEE 1800-2023 section 32
    [CAS-DTINPCIL] Dynamic type in non-procedural context: 'specify' block is not permitted inside package per IEEE 1800-2023 section 32
    [CAS-DTINPCIL] Dynamic type in non-procedural context: 'specify' block is not permitted inside class per IEEE 1800-2023 section 32
    ```
  - Prohibits specify path terminals connected to variables or `reg`:
    ```text
    [CAS-DTINPCIL] Dynamic type in non-procedural context: specify path terminal '<scoped_name>' cannot be a variable/reg per IEEE 1800-2023 section 32
    ```

## 2. Technical Architecture & Implementation Mechanics

### A. Frontend Lexing & Timescale Handling ([`lexer.hpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/include/frontend/lexer.hpp), [`lexer.cpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/src/frontend/lexer.cpp))
- Added `TokenType::TOKEN_SPECIFY`, `TOKEN_ENDSPECIFY`, `TOKEN_FAT_ARROW` (`=>`), `TOKEN_STAR_ARROW` (`*>`), and `TOKEN_IFNONE`.
- Implemented preprocessor directive parsing for `` `timescale <unit> / <precision> ``:
  - Computes global timescale multiplier ratio based on decade difference between unit and precision (e.g., `1ns/100ps` -> 10).
  - Defaults ratio to 1 when no `` `timescale `` directive is present.
  - Added `Lexer::get_timescale_ratio()` and `Lexer::reset_timescale()`.

### B. AST Representation & Parsing ([`ast_module.hpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/include/frontend/ast_module.hpp), [`parser_module.cpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/src/frontend/parser_module.cpp), [`parser_stmt.cpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/src/frontend/parser_stmt.cpp))
- Defined `PathDelayNode` struct containing sources, destinations, `is_full_connection`, condition expression (`cond_expr`), and delay expression (`delay_expr`).
- Added `std::vector<std::shared_ptr<PathDelayNode>> path_delays;` to `ModuleNode`.
- In `Parser::parse_statement()`: enforced diagnostic `[CAS-DTINPCIL]` if `TOKEN_SPECIFY` is encountered in procedural blocks.
- In `Parser::parse_statement()`: updated `#` delay statement parsing to multiply integer and real literals by `Lexer::get_timescale_ratio()` using `std::round`.
- In `Parser::parse_module()`:
  - Enforced diagnostic `[CAS-DTINPCIL]` if `specify` is declared in an interface or program block.
  - Parsed specify blocks containing parallel paths `(src => dst) = delay;` and conditional paths `if (cond) (src => dst) = delay;`.
- In `Parser::parse_package()` and `Parser::parse_class()`: enforced diagnostic `[CAS-DTINPCIL]` if `specify` is declared.

### C. Kernel Elaboration ([`netlist.hpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/include/kernel/netlist.hpp), [`elaborator.hpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/include/kernel/elaborator.hpp), [`elaborator.cpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/src/kernel/elaborator.cpp), [`engine.hpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/include/engine.hpp), [`engine.cpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/src/engine.cpp))
- Defined `ModulePathDelay` struct (`src_net_id`, `dst_net_id`, `cond_expr`, `scope`, `delay_ticks`).
- In `Elaborator::elaborate_module`:
  - Resolved source and destination terminals in module scope.
  - Checked that path terminals are nets (prohibiting `NetKind::VAR` with diagnostic `[CAS-DTINPCIL]`).
  - Evaluated constant delay expressions scaled by the timescale ratio.
  - Remapped terminal NetIDs through alias DSU canonical mapping.
  - Initialized destination nets to 4-state `'x'` (`LogicVal::make_x`).
  - Tracked net toggles with `changed_in_current_sim_time`.
- Loaded module path delay structures into `Engine::module_path_delays`.

### D. Kernel Scheduling & Inertial Delays ([`scheduler.hpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/include/kernel/scheduler.hpp), [`scheduler.cpp`](file:///i:/CAS_Cycle_Accurate_Simulator/CAS/src/kernel/scheduler.cpp))
- Defined `PendingSpecifyNetEvent` (`net_id`, `new_val`, `target_time`) and `pending_specify_events` map keyed by destination NetID.
- In `StratifiedScheduler::propagate_comb`:
  - When a target net with path delay has driver changes where the source net toggled in the current time slot and condition is satisfied, calculated scheduled transition time `current_sim_time + min_delay`.
  - Registered the scheduled update in `pending_specify_events[target_id]` and scheduled a wakeup on the time wheel.
  - Preempted previous pending events according to inertial delay semantics.
  - Prevented premature zero-delay continuous assignment overwrites while an inertial delay event is pending.
- In `StratifiedScheduler::transfer_due_delayed_updates`:
  - Committed matured specify events to `engine.netlist` at current simulation time.
- In `StratifiedScheduler::run_simulation`:
  - Reset `changed_in_current_sim_time = false` across all nets at each new time wheel slot.
