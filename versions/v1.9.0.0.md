# Release v1.9.0.0: Event-Based Intra-Assignment Timing Controls

## 1. Overview & Milestone Scope
This release delivers **v1.9.0.0** of the Cycle Accurate Simulator (CAS), implementing full IEEE Std 1800-2023 compliance for:
- **§10.6.2 (Event-Based Intra-Assignment Timing Controls)**:
  - Immediate RHS Evaluation: The RHS expression is evaluated immediately in the current Active region at the exact timestamp and delta the assignment statement executes.
  - Non-blocking Intra-Event Assignments (`variable <= @(event_control) expr;`): The evaluated RHS value is placed in a pending intra-event buffer; the calling process advances immediately without suspension. Upon the occurrence of the specified event control (e.g. `posedge clk`), the buffered value is committed to the target variable in the stratified NBA region.
  - Blocking Intra-Event Assignments (`variable = @(event_control) expr;`): The evaluated RHS value is buffered; the calling process suspends immediately. Upon the occurrence of the specified event control, the process awakens in the Active region, immediately commits the pre-evaluated value to the target variable, and continues procedural execution.
- **Hierarchical Interconnect & Stratified Signal Propagation**:
  - Immediate combinational synchronization across hierarchical slice bindings (`slice_bindings`) during initial process stepping and delta loop iterations.
  - Robust multi-cycle process looping and re-registration across edge transitions without queue corruption or iterator invalidation.
- **IEEE Std 1800-2023 §21.2.1.3 Multi-bit Hex Formatting (`%h`)**:
  - Full support for 4-state nibble formatting in `%h`, correctly emitting `xx` for 8-bit unknown variables to guarantee exact line-for-line Synopsys VCS reference output.
  - Standard `%%` escape sequence handling in `$display` and `$monitor`.

## 2. Key Architecture Achievements & Refactorings

### A. Frontend Lexical & AST Grammar
- **AST Nodes (`ast_stmt.hpp`)**:
  - Extended `BlockingAssignNode`, `NonBlockingAssignNode`, and `MemAssignNode` with intra-event attributes:
    - `has_intra_event`: Flag indicating active event-based intra-assignment control.
    - `intra_edge`: Trigger edge type (`EdgeType::POSEDGE`, `EdgeType::NEGEDGE`, `EdgeType::LEVEL`).
    - `intra_signal`: Qualified trigger signal name.
    - `set_intra_event(EdgeType edge, std::string sig)`: Method to configure event control parameters cleanly without virtual overhead.
- **Statement Parser (`parser_stmt.cpp`)**:
  - Unified `parse_intra_timing` lambda supporting both intra-assignment delays (`#<number>`) and intra-assignment event controls (`@(<edge> <identifier>)`).
  - Supports non-blocking assignments (`<=`), blocking assignments (`=`), memory word assignments (`mem[addr] = ...`), and concatenation targets (`{a, b} = ...`).

### B. Stratified Scheduler & Delta Wheel Integration
- **Queue Structures (`scheduler.hpp`)**:
  - `IntraEventNbaItem`: Holds `{net_id, val, edge, trigger_net_id, reg_time}` for deferred NBA commitments.
  - `IntraEventBlockingItem`: Holds `{pid, target_name, scope, val, edge, trigger_net_id, reg_time}` for suspended process wakeups.
- **Safe Queue Mutation & Stratified Execution (`scheduler.cpp`)**:
  - Implemented safe vector swap pattern (`current_items.swap(queue)`) in `trigger_intra_event_nbas()` and `trigger_intra_event_blocking()` to prevent iterator invalidation and ensure newly scheduled intra-assignments registered during process reactivation are fully preserved.
  - Timestamp filtering (`item.reg_time >= current_sim_time`) prevents newly queued assignments from prematurely triggering on the awakening edge.
  - Immediate combinational propagation (`propagate_comb()`) during initial simulation startup and delta cycles ensures module inputs are valid before expressions are sampled.

### C. Evaluation & 4-State Display Formatting (`evaluator.cpp`, `logic_val.hpp`)
- **Evaluator Dispatch**:
  - `NonBlockingAssignNode` routes intra-event assignments directly into `queue_intra_event_nba(...)`.
  - `step_process(...)` intercepts `BlockingAssignNode` with intra-events, evaluating RHS immediately, incrementing program counter, queuing into `queue_intra_event_blocking(...)`, and suspending execution cleanly.
- **Standardized Hex Formatting**:
  - Added `LogicVal::to_hex_string(bool unpadded)` to format each nibble according to IEEE 1800-2023 4-state rules.
  - Corrected `%%` format specifier escaping in `$display` and `$monitor`.
