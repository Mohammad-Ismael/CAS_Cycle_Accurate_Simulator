# Release v1.2.0.0: Context-Determined Expression Widths & Signed Arithmetic

## 1. Overview & Milestone Scope
This release delivers **v1.2.0.0** of the Cycle Accurate Simulator (CAS), implementing strict **IEEE Std 1800-2023 Chapter 11 (Expression Bit-Width & Sign Extension Rules)**. The simulation engine now handles signed data types, two's complement preservation, context-determined width calculation, and arithmetic shifts (`>>>`) with verified parity against Synopsys VCS.

---

## 2. Key Architecture Achievements & Refactorings

### A. Context-Determined Bit-Width & Casting (§11.6)
- **`LogicOps::cast_width` (`CAS/include/kernel/logic_ops.hpp`)**:
  - Automatically handles widening and truncation based on the target net's destination width.
  - Correctly sign-extends signed vectors during widening and zero-extends unsigned vectors.
  - Implements unknown-state extension: if the MSB sign bit is `X` or `Z`, all extended bits resolve to `X` per §11.8.2.
- **Context-Determined Adders/Subtractors**:
  - In `Evaluator::eval_expr`, arithmetic operations extend operands prior to computation, matching the target assignment context and preventing premature intermediate truncation.

### B. Signed Data Types & Arithmetic (§11.8)
- **Signed Signal Support**:
  - Extended `PortNode`, `SignalNode`, and `Net` structures to record signedness (`is_signed`).
  - Added `TOKEN_SIGNED` in the lexer and parsed type modifiers for ports, internal wires, logic, and integers (`integer` defaults to signed 32-bit).
- **Signed Comparisons & Operations**:
  - Implemented signed relational checks (`<`, `<=`, `>`, `>=`) using two's complement sign-casting.

### C. Arithmetic Right Shift (`>>>`) (§11.4.10)
- **`LogicOps::arith_shift_right`**:
  - Added dedicated token `TOKEN_ASHR` (`>>>`) to the lexer and expression parser.
  - Differentiates signed vs. unsigned right shifts: unsigned operands zero-fill vacated MSBs, while signed operands replicate the sign bit.

### D. Signed Literal Tokenization (`NumberParser`)
- Extended `NumberParser::parse_sized_literal` to recognize signed radix specifiers (`'sb`, `'sh`, `'sd`).
- Handled negative unary literal negation directly within `Parser::parse_unary`.
