## 1. Overview & Capabilities
Milestone v3.45.0.0 introduces complete support for IEEE Std 1800-2023 §6.24.3 bit-stream casting operators, enabling compile-time and runtime serialization of complex data structures into linear bit streams (from left to right / MSB to LSB) and lossless de-serialization / reassembly into target types of identical total bit width.

### Key Features Implemented:
1. **Bit-Stream Types Supported (§6.24.3)**:
   - Any integral type or packed array (e.g. `logic [31:0]`, `bit [7:0]`, `int`).
   - Packed structure types (e.g. `header_t`, `words_t`).
   - Fixed-size unpacked arrays whose elements are bit-stream types (e.g. `typedef logic [7:0] byte_array_t[4];`).
   - Fixed-width memory arrays and local unpacked arrays.

2. **Stream Flattening & Reassembly Mechanics**:
   - **Left-to-Right Flattening**: Source values (scalars, packed structs, and unpacked arrays) are serialized into a sequence of bits from index 0 to $N-1$ and MSB to LSB.
   - **Target Unpacked Array Reassembly**: Slices bits from the source stream into the target array elements ordered by ascending array index (`[0]`, `[1]`, ..., `[size-1]`).
   - **Target Packed Struct Reassembly**: Reassembles bits into packed fields from declared MSB to LSB.
   - **Scalar Vector Reassembly**: Converts bit streams directly into integral values.

3. **Exact Width Match Enforcement & Context Diagnostics (`[CAS-DTINPCIL]`)**:
   - Enforces the IEEE Std 1800-2023 §6.24.3 rule requiring that bit-stream cast source and destination sizes must match exactly. Any bit width mismatch raises:
     `[CAS-DTINPCIL] Bit-stream cast source size (<src> bits) does not match destination type '<dst>' size (<target> bits) per IEEE 1800-2023 section 6.24.3`.
   - Rejects non-bit-stream types (classes, chandles, virtual interfaces) involved in bit-stream casts with:
     `[CAS-DTINPCIL] Non-bit-stream type in bit-stream cast per IEEE 1800-2023 section 6.24.3: '<name>'`.
