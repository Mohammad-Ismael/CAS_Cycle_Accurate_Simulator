## 1. Overview & Capabilities
Milestone v3.47.0.0 implements complete support for IEEE Std 1800-2023 §11.4.13 set membership operator (`inside`), enabling evaluation of candidate expressions against open range lists comprising discrete values and bounded range pairs across procedural code, continuous assignments, and decision predicates.

### Key Features Implemented:
1. **Open Range Lists & Grammar (§11.4.13)**:
   - Syntax: `expr inside { open_range_list }` where items can be discrete expressions or bounded pairs `[low : high]`.
   - Universal integration across procedural blocks (`if (val inside { ... })`), continuous assignments (`assign hit = val inside { ... };`), and clocked processes (`in_reserved_range <= (pkt_addr inside { ... });`).

2. **Bounded Range Evaluation**:
   - Inclusive bounds checking: matches if `(low <= lhs && lhs <= high)` or `(high <= lhs && lhs <= low)`.
   - Automatic signedness inference: if all operands (`lhs`, `low`, `high`) are signed, performs signed integer comparisons (`to_signed()`); otherwise performs unsigned comparisons.

3. **Discrete Value Membership & Wildcard Matching (`==?`)**:
   - Discrete item matching conforms to IEEE Std 1800-2023 §11.4.6 wildcard equality semantics (`LogicOps::wildcard_eq`), treating `x` and `z` in the item as wildcards.

4. **4-State Truth Resolution**:
   - Returns `1'b1` if any element or bounded range in the list matches.
   - Returns `1'b0` if all elements/ranges fail to match and all comparisons are known 2-state values.
   - Returns `1'bx` if no match is found but at least one comparison evaluates to unknown (`x`/`z`).

5. **Context Diagnostics (`[CAS-DTINPCIL]`)**:
   - Prohibits empty open range lists (`val inside {}`) with:
     `[CAS-DTINPCIL] Inside operator open range list cannot be empty per IEEE 1800-2023 section 11.4.13`.
   - Enforces valid bracket and colon syntax in bounded ranges (`[low : high]`) with:
     `[CAS-DTINPCIL] Inside operator bounded range item lacks valid colon syntax per IEEE 1800-2023 section 11.4.13`.
   - Rejects non-integral bounds (such as strings or reals in ranges) with:
     `[CAS-DTINPCIL] Inside operator bounded range bounds must be integral values per IEEE 1800-2023 section 11.4.13`.
