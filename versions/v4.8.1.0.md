### Key Technical Achievements

1. **Indexed Part-Select (`+:` / `-:`) Return Fix in Evaluator (`CAS/src/kernel/expr_evaluator.cpp`)**:
   - In `eval_index_select` for signal nets (`assign a_wmask[k] = &a_wmask_i[k*8 +: 8]`), `return target_val.extract_slice(lsb, slice_w);` was improperly placed inside an `else` branch, causing `+:` and `-:` part-selects to fall through and return `1'bx`.
   - In Ibex `prim_ram_2p`, this converted `a_wmask` into `1'bx`, silently suppressing memory write strobes and skipping function stack frames in SRAM.
   - At cycle 837, `c.lwsp` loaded uninitialized `0xffffffff` as `0xxxxxxxxx`, and `c.jr` jumped to `0xxxxxxxxx`, triggering an instruction access fault exception at cycle 845 (`MEPC = 0x0`).
   - Moved `return target_val.extract_slice(lsb, slice_w);` outside the `if-else` chain so all indexed and fixed part-selects return proper slices.
   - Verified that `c.lwsp` now restores valid stack pointers and return addresses with 0 'x' bits, and Ibex executes cleanly into the timer interrupt loop with ZERO hardware exceptions.

2. **Spike Lockstep Verifier Hardening (`scripts/verify_ibex_spike.py`)**:
   - Added regex audit in `parse_cas_trace` rejecting any trace containing uninitialized `'x'` or `'z'` values in register writeback (`re.search(r"\b(x\d+)=0x[0-9a-fA-F]*[xXzZ]", reg_col)`).
   - Removed artificial 60-instruction cap; verifier now validates 100% of all retired instructions produced by CAS (`min(len(cas_events), len(spike_events))`), achieving 178 / 178 instructions (100.0% parity).

3. **Ibex SoC Demo Hardening (`scripts/run_ibex_demo.sh`)**:
   - Added strict checks asserting zero hardware exceptions (`EXCEPTION!!!`) and zero `'x'`/`'z'` in `trace_core_00000000.log`.
   - Updated default horizon to 1,600 cycles, verifying UART capture of `Hello simple system`, `DEADBEEF`, and `BAADF00D`.
