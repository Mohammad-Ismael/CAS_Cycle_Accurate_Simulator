## 1. Release Overview & Scope

CAS `v4.3.1.0` achieves **100.0% compliance on all 62 positive parsing and preprocessing tests across IEEE 1800-2023 Chapters 5 through 26 in `sv-tests`**, in addition to maintaining **100.0% (283/283) positive simulation parity** and passing all **107/107 milestone regressions**.

### Key Capabilities Delivered in v4.3.1.0:
- **Macro Empty Arguments & Trailing Commas (IEEE Std 1800-2023 §22.5.1)**:
  - Full support for omitted and empty actual arguments in macro invocations (e.g., `` `M(a, ) ``, `` `M(, b) ``, `` `M(,) ``).
  - Default formal argument fallback when actual arguments are empty or omitted.
  - Robust tracking of string literal boundaries and escape sequences inside macro invocations so commas within strings (e.g., `` `uvm_info("TAG", "Message, with comma", UVM_LOW) ``) are properly preserved.
- **`line Compiler Directive (IEEE Std 1800-2023 §22.12)**:
  - Full ingestion and tracking of `` `line <line_number> "<filename>" <level> `` directives.
  - Accurate AST and diagnostics attribution to virtual files and line offsets.
- **Gate Delay Specification Support (§28.16)**:
  - Gate delay parsing `#delay`, `#(delay)`, or `#(rise, fall)` directly before gate instance names or port lists.
- **Consecutive Commas & Empty Arguments in `$display` / `$monitor` (§21.2.1)**:
  - Support for consecutive commas (e.g., `$display(a,,b,,c);` or `$display(, a, b);`), outputting a single space per IEEE 1800-2023 §21.2.1.
  - Dynamic printing of all trailing arguments following format strings.
- **CLI Options for Modular Compiler Execution**:
  - `--parse-only`: Completes front-end lexing and AST construction then exits with code 0.
  - `--elab-only`: Completes elaboration and netlist synthesis then exits with code 0.
- **UVM Testbench Layer**:
  - Verification of standalone UVM testbenches (`uvm_test_run_test.sv`, `uvm_sequence.sv`, `uvm_files.sv`).
