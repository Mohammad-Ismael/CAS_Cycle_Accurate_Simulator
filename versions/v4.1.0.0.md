## 1. Release Overview & Scope

CAS `v4.1.0.0` extends the milestone IEEE Std 1800-2023 compliance baseline from Chapters 5–12 across Chapters 13, 14, and 15, achieving **100.0% execution parity (171/171 passing simulation tests)** across IEEE 1800-2023 Chapters 5 through 15 in the industry-standard `sv-tests` conformance suite. In addition, `v4.1.0.0` incorporates **101 consecutive milestone regression test suites (`v1.0.0.0` through `v4.1.0.0`)** and verifies full RV32IMC execution of the lowRISC Ibex processor core.

### Key Capabilities Delivered in v4.1.0.0:
- **IEEE Std 1800-2023 §13.3.1 Task Lifetime Management**:
  - `task automatic`: Guaranteed per-invocation dynamic frame allocation and local variable re-initialization.
  - `task static`: Guaranteed static storage persistence across subroutine invocations, preserving local variable state without re-running declarations.
- **IEEE Std 1800-2023 §13.4.3 Constant Function Elaboration**:
  - Complete compile-time / elaboration evaluation of functions invoked within `localparam` and `parameter` assignments.
  - Constant function recursion and multi-statement control flow resolution during the elaboration phase.
- **100% IEEE Std 1800-2023 Chapters 5–15 Compliance**:
  - **Chapter 5:** Lexical Conventions (Syntactic)
  - **Chapter 6:** Data Types (1/1 PASS)
  - **Chapter 7:** Aggregate Data Types (90/90 PASS)
  - **Chapter 8:** Classes & OOP (6/6 PASS)
  - **Chapter 9:** Processes & Event Control (5/5 PASS)
  - **Chapter 10:** Assignment Statements (2/2 PASS)
  - **Chapter 11:** Operators & Expressions (51/51 PASS)
  - **Chapter 12:** Procedural Control Statements (2/2 PASS)
  - **Chapter 13:** Tasks and Functions (12/12 PASS)
  - **Chapter 14:** Clocking Blocks (0/0 Syntactic)
  - **Chapter 15:** Interprocess Synchronization & Communication (2/2 PASS)
- **lowRISC Ibex RV32IMC Verification**:
  - Full elaboration of 137 modules, 2,710 nets, and 125 memory arrays.
  - Successful boot sequence, BSS zeroing, CSR initialization, UART console output (`Hello simple system`, `DEADBEEF`, `BAADF00D`), and timer interrupt handling.
