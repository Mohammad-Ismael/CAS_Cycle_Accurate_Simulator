## 1. Landmark Overview & Architectural Scope

CAS `v4.0.0.0` represents a monumental milestone in the development of the Cycle-Accurate Simulator: achieving **100.0% execution parity (157/157 passing tests)** across all simulation test suites of **IEEE Std 1800-2023 Chapters 5 through 12** in `sv-tests`, supported by **100 consecutive milestone regression test suites (`v1.0.0.0` through `v4.0.0.0`)** passing with zero failures against golden references.

### Key Capabilities Delivered in v4.0.0.0:
- **IEEE Std 1800-2023 §7.4.3 & §7.6 Canonical Left-to-Right Unpacked Array Assignment**:
  - Full conformance with left-to-right positional copying for whole-array and sub-slice assignments across differing dimension directions:
    - Descending (`[N:0]`) to ascending (`[0:N]`) array assignments correctly map elements from left-to-right (`arr_asc[0] = arr_desc[N]`, etc.).
    - Asymmetric and mixed-direction sub-slice assignments (`sub_asc[0:1] = arr_desc[3:2]`, `sub_desc[3:2] = arr_asc[0:1]`).
  - Unified array element retrieval in `ExprEvaluator` (`eval` and `get_array_elements`) guaranteeing exact sequential element ordering conforming to IEEE 1800-2023 §7.6.
- **100% IEEE Std 1800-2023 Chapters 5–12 Compliance**:
  - **Chapter 5:** Lexical Conventions (whitespace, comments, identifiers, escaped identifiers, numbers, strings).
  - **Chapter 6:** Data Types (scalar 2-state and 4-state logic, vectors, nets, enums, structs, tagged unions, user-defined types).
  - **Chapter 7:** Aggregate Data Types (packed and unpacked multidimensional arrays, dynamic arrays, queues, associative arrays, reduction methods, ordering methods, locator methods).
  - **Chapter 8:** Classes & Object-Oriented Programming (encapsulation, constructors, inheritance, polymorphism, virtual interfaces, interface classes, parameter overrides).
  - **Chapter 9:** Processes & Event Control (procedural blocks, `initial`, `always`, `always_comb`, `always_ff`, `always_latch`, fork-join variants, fine-grained process control).
  - **Chapter 10:** Assignment Statements (blocking, non-blocking with intra-assignment delays, continuous assignments, procedural continuous assignments).
  - **Chapter 11:** Operators & Expressions (arithmetic, bitwise, reduction, logical, relational, equality 2-state and 4-state, ternary, inside, streaming, casting).
  - **Chapter 12:** Procedural Control Statements (selection, loops, `unique`/`priority` case, jump statements).
