# Release v3.33.0.0: Array Querying Functions ($size, $dimensions, $unpacked_dimensions, $left, $right, $low, $high, $increment), Multi-Dimensional Arrays, Dynamic Arrays, Queues, and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §7.11)

## 1. Overview & Milestone Scope
This release delivers **v3.33.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **68.2%** (`[████████████████████████████████████░░░░░░░░░░] 68.2%`) and implementing full IEEE Std 1800-2023 compliance for:
- **§7.11 (Array Querying Functions)**:
  - Built-in array query system functions:
    * `$dimensions(array_or_type)`: Returns the total number of dimensions (unpacked dimensions + packed dimensions, or 1 for scalar bit vectors).
    * `$unpacked_dimensions(array_or_type)`: Returns the number of unpacked dimensions.
    * `$left(array_or_type [, dimension])`: Returns the declared left bound of the specified dimension.
    * `$right(array_or_type [, dimension])`: Returns the declared right bound of the specified dimension.
    * `$low(array_or_type [, dimension])`: Returns the minimum of `$left` and `$right`.
    * `$high(array_or_type [, dimension])`: Returns the maximum of `$left` and `$right`.
    * `$increment(array_or_type [, dimension])`: Returns `1` if `$left >= $right` (descending range, e.g. `[15:0]`), or `-1` if `$left < $right` (ascending range, e.g. `[0:15]`).
    * `$size(array_or_type [, dimension])`: Returns the number of elements in the specified dimension (`$high - $low + 1`).
- **§7.11.1 (Multi-Dimensional Dimension Indexing Order)**:
  - Dimension `1` corresponds to the leftmost unpacked dimension.
  - Numbering continues left-to-right across all unpacked dimensions (`1 .. N_unpacked`).
  - Packed dimensions follow unpacked dimensions, continuing left-to-right (`N_unpacked + 1 .. N_total`).
  - Default dimension argument is `1` when omitted.
- **§7.11.6 (Dynamic Arrays and Queues Support)**:
  - Dynamic array variables (`int dyn[]`) and queues (`int q[$]`) queryable at runtime.
  - Dimension bounds dynamically report current allocation:
    * `$left` = 0
    * `$right` = `N - 1`
    * `$low` = 0
    * `$high` = `N - 1`
    * `$increment` = -1
    * `$size` = `N`
- **Context Diagnostics & Semantic Restrictions (`[CAS-DTINPCIL]`)**:
  - Out-of-bounds dimension argument (`dim < 1 || dim > total_dims`) caught and reported with diagnostic `[CAS-DTINPCIL]`.
  - Non-array, non-vector variables queried with `$dimensions` or query functions caught with diagnostic `[CAS-DTINPCIL]`.
