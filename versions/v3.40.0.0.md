## 1. Overview & Capabilities
Milestone v3.40.0.0 implements native support for IEEE Std 1800-2023 §11.12, providing package-, module-, interface-, and block-scoped `let` declarations, untyped and typed formal argument lists, default actual values, argumentless invocations, inline AST expression tree expansion with formal substitution, and context diagnostic `[CAS-DTINPCIL]`.

### Key Features Implemented:
1. **'let' Grammar & Declaration Scopes (§11.12)**:
   - Added AST nodes `LetDeclNode`, `LetPortItem`, and `LetStatementNode`.
   - Added lexer tokens `TOKEN_LET` (`let`) and `TOKEN_UNTYPED` (`untyped`).
   - Parsed package-level `let` declarations (`package ... endpackage`), storing into `PackageNode::let_decls`, `PackageNode::let_decl_map`, and `Parser::global_let_decls[pkg::name + "::" + name]`.
   - Parsed module/interface-level `let` declarations, storing into `ModuleNode::let_decls` and `ModuleNode::let_decl_map`.
   - Parsed block/procedural-level `let` declarations inside `parse_statement()`, generating no-op `LetStatementNode` runtime statements.
   - Cleared `Parser::global_let_decls` in `Parser::clear_global_packages()`.

2. **Typed & Untyped Formal Arguments with Defaults (§11.12.1)**:
   - Supported untyped formal arguments (`untyped x` or plain `x`) and typed arguments (`logic [7:0] d`, `bit v`, `int`, etc.).
   - Supported default values on formal ports (`let f(x, min_bound = 8'd10) = ...`).
   - Position-based and named-argument binding (`.port(expr)`) at call sites with default value fallbacks.
   - Supported empty argument slots taking defaults.
   - Integrated automatic type casting for typed formals using `CastNode` with bit-width truncation / zero-extension / sign-extension.

3. **Inline AST Expression Substitution & Recursion Prevention (§11.12)**:
   - Implemented `find_visible_let()` resolving package-qualified (`pkg::let`), local module, explicitly imported, wildcard imported, and compilation-unit `let` declarations.
   - Implemented `expand_let()` and `substitute_let_in_expr()` performing inline expression tree cloning and argument substitution.
   - Supported argumentless `let` declarations called with or without empty parentheses (`let f = expr; ... y = f;`).
   - Prevented direct and mutual recursion using `active_let_expansions` and AST traversal with context diagnostic `[CAS-DTINPCIL]`.
   - Prohibited side effects and state modifications (`=`, `+=`, `++`, etc.) inside `let` expressions with `[CAS-DTINPCIL]`.
   - Enforced missing mandatory argument validation with `[CAS-DTINPCIL]`.
