# Release v3.21.0.0: SystemVerilog Assertions (SVA) Local Variables in Sequences & Properties, Sequence Match Variable Assignments '(seq_expr, var = expr)', Multi-Thread State Isolation Across Delayed Consequents '##N', and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §16.10)

## 1. Overview & Milestone Scope
This release delivers **v3.21.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **51.4%** and implementing full IEEE Std 1800-2023 compliance for:
- **§16.10 (SystemVerilog Assertions: Local Variables in Sequences & Properties)**:
  - **Local Variable Declarations**:
    - Declarations permitted within `property ... endproperty` and `sequence ... endsequence`:
      ```systemverilog
      property p_name;
          data_type variable_identifier [ = init_val ];
          property_spec;
      endproperty
      ```
    - Support for `logic`, `bit`, `reg`, `int`, `byte`, `shortint`, `longint`, explicit bit-width vectors `[msb:lsb]`, signed modifiers, and comma-separated declarations.
  - **Sequence Match Variable Assignments**:
    - Attach match assignments to subexpressions:
      ```systemverilog
      (sequence_expression, variable_identifier = expression { , variable_identifier = expression })
      ```
    - Immediate execution of match assignments when the subexpression matches, updating thread-local variables using Preponed sampled values.
  - **Leading Sequence Cycle Delays (`##N`)**:
    - Support for leading cycle delays in consequents: `(ant) |-> ##N (cons)`.
    - Proper calculation of remaining thread delays for overlapping (`|->`) and non-overlapping (`|=>`) implications.
  - **Multi-Thread State Isolation**:
    - Per-thread variable storage (`SvaThread.local_vars`).
    - Concurrent assertion threads maintain isolated local variable values across delayed consequents without state pollution.
  - **Dynamic Context Diagnostic Enforcement (`[CAS-DTINPCIL]`)**:
    - Rejection of sequence and property local variables in non-procedural contexts such as continuous assignments (`assign`) and `$monitor` with diagnostic `[CAS-DTINPCIL]`.
    - Rejection of sequence match items used directly in continuous assignments or `$monitor`.

## 2. Technical Architecture & Implementation Mechanics

### A. Frontend AST Nodes (`CAS/include/frontend/ast_expr.hpp`, `CAS/include/frontend/ast_module.hpp`, `CAS/include/common/sva_types.hpp`)
- Added `SequenceMatchAssignment` and `SequenceMatchItemNode` AST nodes with recursive `clone()` methods.
- Added `SvaLocalVar` struct holding variable name, bit-width, and signedness.
- Added `std::vector<SvaLocalVar> local_vars;` to `PropertyNode`, `SequenceNode`, and `SvaAssertionInstance`.
- Added `std::map<std::string, LogicVal> local_vars;` to `SvaThread` for thread-isolated state.

### B. Parser Implementation (`CAS/src/frontend/parser_expr.cpp`, `CAS/src/frontend/parser_module.cpp`, `CAS/src/frontend/parser_stmt.cpp`)
- In `parse_primary()`:
  - Extended parenthesized sequence expression parsing to recognize `, var = expr` match assignments and construct `SequenceMatchItemNode`.
- In `parse_sequence_expression()`:
  - Added support for leading cycle delays `##N` at the beginning of sequence expressions, constructing `SequenceConcatNode`.
- In `parse_property()`, `parse_sequence()`, and `parse_assert_property()`:
  - Added local variable declaration parsing before clock and sequence expressions.
- In `parse_statement()`:
  - Added compile-time unrolling of `repeat (N)` loops containing timing controls (`@(posedge clk)`, `#delay`).

### C. Kernel Expression Evaluator (`CAS/include/kernel/expr_evaluator.hpp`, `CAS/src/kernel/expr_evaluator.cpp`)
- Added `current_sva_local_vars` pointer and getter/setter `set_sva_local_vars()`.
- In `eval(IdentifierNode*)`:
  - Resolved identifier against `current_sva_local_vars` first when evaluating in an active SVA thread context.
- In `eval(IndexSelectNode*)`:
  - Resolved bit-selects and part-selects on SVA thread-local variables.
- In `eval(SequenceMatchItemNode*)`:
  - Evaluated sequence condition; on match, evaluated and stored RHS values into `current_sva_local_vars`.
  - Raised diagnostic `[CAS-DTINPCIL]` if evaluated outside SVA context.

### D. Kernel Elaboration & Context Enforcement (`CAS/src/kernel/elaborator.cpp`, `CAS/src/kernel/evaluator.cpp`)
- Registered local variable names into `ElaborationResult.sva_local_var_names` and `Engine.sva_local_var_names`.
- Replaced illegal continuous assignments to SVA local variables with diagnostic `[CAS-DTINPCIL]`.
- Replaced illegal references to SVA local variables in `$monitor` with diagnostic `[CAS-DTINPCIL]`.

### E. Stratified Scheduler SVA Engine (`CAS/src/kernel/scheduler.cpp`)
- On clock edge evaluation:
  - Instantiated `new_th` with initialized thread-local variable table.
  - Evaluated antecedent with `set_sva_local_vars(&new_th.local_vars)`, capturing preponed values during match assignments.
  - Calculated `remaining_delay` accounting for leading cycle delays in the consequent.
  - Evaluated consequent steps in `advance_thread` using thread-specific local variables.
