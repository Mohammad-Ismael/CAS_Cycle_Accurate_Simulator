## 1. Overview & Capabilities
Milestone v3.51.0.0 implements complete support for IEEE Std 1800-2023 §20.8 integer math system function `$clog2`, providing ceiling log2 evaluation across elaboration-time parameter and port declarations, package definitions, continuous assignments, and procedural runtime contexts, complete with 4-state unknown propagation and context diagnostic enforcement `[CAS-DTINPCIL]`.

### Key Features Implemented:
1. **Mathematical Ceiling Base-2 Logarithm (§20.8.1)**:
   - Syntax: `$clog2(expression)`.
   - Computes $\lceil\log_2(\text{value})\rceil$.
   - Conforms to standard boundary condition table:
     * `value <= 1` $\rightarrow$ returns `0` (`$clog2(0) = 0`, `$clog2(1) = 0`).
     * `value > 1` $\rightarrow$ returns the smallest integer $k$ such that $2^k \ge \text{value}$.
   - Negative values: evaluated using two's complement unsigned representation.

2. **Elaboration-Time Constant Evaluation & Sizing**:
   - Parameter assignments: `parameter int ADDR_WIDTH = $clog2(DEFAULT_DEPTH);`
   - Localparams: `localparam int PTR_BITS = $clog2(BUFFER_ENTRIES);`
   - Vector bounds & port ranges: `output logic [$clog2(BUFFER_ENTRIES)-1:0] wr_ptr;`
   - Memory array dimensions: `logic [7:0] mem [BUFFER_ENTRIES];`
   - Package-scoped parameters evaluated in `Parser::eval_const_expr_with_params` and module instances in `Elaborator::eval_const_expr`.

3. **4-State Unknown Handling**:
   - If `expression` contains unknown bits (`x` or `z`, i.e. `bval != 0`), the runtime evaluation returns a 32-bit unknown value (`'bx`).

4. **Context Diagnostics (`[CAS-DTINPCIL]`)**:
   - Strictly enforces exactly one argument:
     `[CAS-DTINPCIL] $clog2 requires exactly one argument per IEEE 1800-2023 section 20.8.1`
   - Rejects zero arguments `$clog2()` or multiple arguments `$clog2(a, b)`:
     `[CAS-DTINPCIL] $clog2 requires exactly one argument per IEEE 1800-2023 section 20.8.1`
   - Rejects non-integral / non-packed arguments (e.g. class handles, chandles, strings, reals):
     `[CAS-DTINPCIL] Non-integral argument passed to $clog2 per IEEE 1800-2023 section 20.8.1`
