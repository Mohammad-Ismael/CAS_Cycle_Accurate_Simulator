# Release v2.7.0.0: Fixed-Size Unpacked Arrays, Memory Element Indexing, and 4-State Out-of-Bounds Semantics

## 1. Overview & Milestone Scope
This release delivers **v2.7.0.0** of the Cycle Accurate Simulator (CAS), implementing full IEEE Std 1800-2023 compliance for:
- **§7.4 (Unpacked Arrays)**:
  - Declarations with unpacked dimensions following the identifier name:
    ```systemverilog
    logic [width-1:0] array_name [start:end];
    logic [width-1:0] array_name [size]; // [0:size-1]
    ```
  - Independent vector element modeling: each element in an unpacked array represents a standalone 4-state vector of the base width (`word_width`).
  - Support for arbitrary index bounds: ascending index ranges (`[0:3]`, `[1:8]`), descending index ranges (`[3:0]`), and single-dimension size specifications (`[16]`).
- **§7.4.2 (Memory & Array Element Indexing)**:
  - Dynamic index expressions on both RHS and LHS:
    ```systemverilog
    // Read access
    rdata = reg_file[raddr];

    // Synchronous non-blocking write access
    reg_file[waddr] <= wdata;

    // Procedural blocking write access
    reg_file[waddr] = wdata;
    ```
- **§7.4.6 (Array Slicing and 4-State Out-of-Bounds Semantics)**:
  - **Read Access Out-of-Bounds / Unknown**: If an index expression evaluates to a value that falls outside the declared index bounds, or contains any unknown (`'x`) or high-impedance (`'z`) bits, the read operation returns a 4-state vector of `'x` matching the array element's declared bit-width (e.g. `8'hxx`).
  - **Write Access Out-of-Bounds / Unknown**: If an index expression evaluates to an out-of-bounds address or contains `'x` or `'z'`, the assignment has zero effect on any element of the array. No memory corruption, partial write, or out-of-bounds memory access occurs.

## 2. IEEE Std 1800-2023 Semantics & Mechanics

### A. MemoryArray Structural Representation & Addressing Mapping
- During elaboration (`Elaborator::elaborate_module`), declarations containing unpacked array dimensions (`s.is_array`) are synthesized into `MemoryArray` instances within `Engine::memory_map`:
  ```cpp
  struct MemoryArray {
      std::string name;
      uint32_t word_width = 32;
      uint32_t depth = 0;
      int64_t start_idx = 0;
      int64_t end_idx = 0;
      bool is_descending = false;
      std::vector<LogicVal> words;

      MemoryArray() : word_width(32), depth(0), start_idx(0), end_idx(0), is_descending(false) {}
      MemoryArray(std::string n, uint32_t w, uint32_t d, int64_t b1 = 0, int64_t b2 = 0)
          : name(std::move(n)), word_width(w), depth(d) {
          if (b1 <= b2) {
              start_idx = b1;
              end_idx = b2;
              is_descending = false;
          } else {
              start_idx = b2;
              end_idx = b1;
              is_descending = true;
          }
          words = std::vector<LogicVal>(d, LogicVal::make_x(w));
      }

      bool is_valid_index(int64_t idx) const {
          return (idx >= start_idx && idx <= end_idx);
      }

      size_t to_word_offset(int64_t idx) const {
          if (is_descending) {
              return (size_t)(end_idx - idx);
          } else {
              return (size_t)(idx - start_idx);
          }
      }

      LogicVal get_word(int64_t idx) const {
          if (!is_valid_index(idx)) return LogicVal::make_x(word_width);
          size_t off = to_word_offset(idx);
          if (off < words.size()) return words[off];
          return LogicVal::make_x(word_width);
      }

      void set_word(int64_t idx, const LogicVal& val) {
          if (!is_valid_index(idx)) return;
          size_t off = to_word_offset(idx);
          if (off < words.size()) {
              words[off] = val;
          }
      }
  };
  ```

### B. Procedural Read Evaluation (RHS)
- In `ExprEvaluator::eval()`:
  - When evaluating an `IndexAccessNode` or bit-select on an identifier, the evaluator first checks `engine.memory_map` (using hierarchical or local scoping).
  - Evaluates the index expression `idx_node->msb_expr`.
  - If the index value contains any unknown/high-Z bits (`addr_val.is_unknown()`), returns `LogicVal::make_x(mem.word_width)`.
  - Otherwise, dispatches `mem.get_word((int64_t)addr_val.aval)`, which validates the index range against `[start_idx, end_idx]` and returns either the indexed word or an unknown vector (`'x`) of the word width.

### C. Procedural Write Commitments (LHS)
- **Non-Blocking Assignment (NBA)**:
  - Parsed as `MemAssignNode` with `is_non_blocking = true`.
  - Evaluates RHS value immediately in the current Active region.
  - If `addr_val.is_unknown()`, the write is ignored per §7.4.6.
  - Otherwise, schedules into `StratifiedScheduler::nba_mem_queue` (or `delayed_nba_mem_queue` if intra-assignment delay `#delay` is present).
  - During scheduler NBA update commitment (`commit_nba_updates`), executes `mem.set_word(mem_up.addr, mem_up.val)`.
- **Blocking Assignment**:
  - Handled in `Evaluator::exec_stmt()` for both `MemAssignNode` (`is_non_blocking = false`) and `BlockingAssignNode` with index target (`assign->bit_idx`).
  - If the target is in `engine.memory_map`, commits synchronously via `mem.set_word(addr, rhs_val)` if the index is valid and known.

## 3. Key Architectural Achievements & Refactorings

### A. Elaborator & Dimension Index Mapping (`elaborator.hpp`, `elaborator.cpp`)
- Added explicit bound tracking (`start_idx`, `end_idx`, `is_descending`) to `MemoryArray`.
- Evaluated constant dimension bounds in `Elaborator::elaborate_module` and constructed `MemoryArray` instances with accurate range bounds.

### B. Stratified Scheduler (`scheduler.hpp`, `scheduler.cpp`)
- Updated `NBAMemUpdate` to support signed 64-bit array indices (`int64_t addr`).
- Updated `queue_nba_mem` and `queue_delayed_nba_mem` signatures and implementations.
- Updated `commit_nba_updates()` and delayed NBA queues to commit memory updates via `mem.set_word()`.

### C. Statement and Expression Evaluators (`evaluator.cpp`, `expr_evaluator.cpp`)
- Unified memory lookups in `evaluator.cpp` and `expr_evaluator.cpp` across local and hierarchical scopes.
- Implemented strict IEEE Std 1800-2023 §7.4.6 4-state unknown index handling (reading `'x` and suppressing out-of-bounds writes).
