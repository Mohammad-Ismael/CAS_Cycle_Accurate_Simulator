## 1. Overview & Capabilities
Milestone v3.50.0.0 implements full support for IEEE Std 1800-2023 §20.9 vector bit-count and intrinsic query system functions (`$countones`, `$onehot`, `$onehot0`, `$isunknown`), providing cycle-accurate 4-state unknown propagation, bit-vector introspection, strict single-argument validation, and context diagnostic enforcement `[CAS-DTINPCIL]` with 100% Synopsys VCS reference parity.

### Key Features Implemented:
1. **Vector Bit-Count Function (`$countones`) (§20.9)**:
   - Syntax: `$countones(expression)`.
   - Returns a 32-bit integer count of the number of bits in `expression` resolving to `1`.
   - Bits resolving to `0`, `x`, or `z` do not increment the count.

2. **Single-Bit Asserted Function (`$onehot`) (§20.9)**:
   - Syntax: `$onehot(expression)`.
   - Returns `1'b1` if one and only one bit of `expression` resolves to `1`.
   - Returns `1'b0` if zero or multiple bits resolve to `1`.
   - Returns `1'b0` if any bit resolves to `x` or `z` (unknown).

3. **At-Most-One-Bit Asserted Function (`$onehot0`) (§20.9)**:
   - Syntax: `$onehot0(expression)`.
   - Returns `1'b1` if at most one bit of `expression` resolves to `1` (zero or one bit set).
   - Fully conforms to IEEE 1800-2023 4-state unknown evaluation: returns `1'b1` when `ones + unknowns <= 1` (e.g. `4'b0000` $\rightarrow$ `1'b1`, `4'b0010` $\rightarrow$ `1'b1`, `4'b000x` $\rightarrow$ `1'b1`, `4'b000z` $\rightarrow$ `1'b1`); returns `1'b0` if multiple bits are `1` or if ambiguous (`4'b0011` $\rightarrow$ `1'b0`, `4'b001x` $\rightarrow$ `1'b0`, `4'b00xx` $\rightarrow$ `1'b0`).

4. **Unknown Bit Introspection Function (`$isunknown`) (§20.9)**:
   - Syntax: `$isunknown(expression)`.
   - Returns `1'b1` if any bit of `expression` resolves to `x` or `z`.
   - Returns `1'b0` if all bits of `expression` resolve to known 2-state values (`0` or `1`).

5. **Context Diagnostics (`[CAS-DTINPCIL]`)**:
   - Strictly enforces exactly one argument:
     `[CAS-DTINPCIL] <func_name> requires exactly one argument per IEEE 1800-2023 section 20.9`
   - Rejects missing arguments `func()` or multiple arguments `func(a, b)`:
     `[CAS-DTINPCIL] $countones requires exactly one argument per IEEE 1800-2023 section 20.9`
   - Rejects non-integral / non-packed arguments:
     `[CAS-DTINPCIL] Non-integral argument passed to <func_name> per IEEE 1800-2023 section 20.9`
