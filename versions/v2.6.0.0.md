# Release v2.6.0.0: Packed Structures, Member Slicing, and Aggregate Vector Conversions

## 1. Overview & Milestone Scope
This release delivers **v2.6.0.0** of the Cycle Accurate Simulator (CAS), implementing full IEEE Std 1800-2023 compliance for:
- **§7.2 (Structures)**:
  - Keyword and grammar support for `typedef struct packed`:
    ```systemverilog
    typedef struct packed [signed/unsigned] {
        [signed/unsigned] logic [width-1:0] member_name;
        ...
    } struct_type_t;
    ```
  - Total bit-width of a packed structure is calculated as the sum of the bit-widths of all its constituent member fields.
  - Sized and unsized member declarations (`logic [msb:lsb]`, `int`, `byte`, `bit`, `integer`, or nested typedef types).
- **§7.2.1 (Packed Structures Bit Layout)**:
  - Canonical SystemVerilog bit order: The first declared field occupies the most significant bits (MSBs), and each subsequent field occupies the next most significant bits, with the last declared field occupying the least significant bits (LSBs).
  - Offset calculation: Member $i$ occupies bits $[(offset_i + width_i - 1) : offset_i]$, where $offset_i$ is the sum of the widths of all subsequent fields ($i+1 \dots k-1$).
- **§7.2 & §7.3.2 (Aggregate Vector Equivalence)**:
  - A packed structure is bitwise equivalent to a contiguous logic vector of the structure's total width.
  - Direct aggregate assignment: Assigning a raw bit vector to a packed structure variable (`rx_pkt = raw_packet_in;`).
  - Direct vector exposure: Continuous assignment or reading of a packed structure as a raw logic vector (`assign packet_loopback = tx_pkt;`).
  - Static type casting: Casting expressions to packed structure types (`type'(expr)`).
- **Member Access & Field Slicing (LHS and RHS)**:
  - Reading member fields in expressions: `rx_pkt.src_id`, `rx_pkt.dst_id`, `rx_pkt.payload`.
  - Writing member fields with blocking assignments: `struct_var.field = expr;`.
  - Writing member fields with non-blocking assignments (NBA): `struct_var.field <= expr;`.
  - Concurrent sibling field NBA updates: Multiple non-blocking assignments updating distinct fields of the same struct in the same simulation cycle commit their respective bit-slices without clobbering each other.

## 2. IEEE Std 1800-2023 Semantics & Mechanics

### A. Packed Structure Type Representation & Bit Offsets (§7.2.1)
- Packed structure definitions parsed into `StructTypeNode` are registered during elaboration into `PackedStructType`:
  ```cpp
  struct StructMember {
      std::string name;
      uint32_t width;
      uint32_t offset; // Bit offset from LSB (0-indexed)
      bool is_signed;
      std::string type_name;
  };

  struct PackedStructType {
      std::string name;
      uint32_t total_width;
      bool is_signed;
      std::vector<StructMember> members;
      const StructMember* get_member(const std::string& member_name) const;
  };
  ```
- Example:
  ```systemverilog
  typedef struct packed {
      logic [3:0] src_id;  // bits [15:12] -> offset = 12, width = 4
      logic [3:0] dst_id;  // bits [11:8]  -> offset = 8,  width = 4
      logic [7:0] payload; // bits [7:0]   -> offset = 0,  width = 8
  } packet_t;              // Total width = 16 bits
  ```

### B. Member Access in Expressions (RHS)
- Represented in AST via `MemberAccessNode(var_name, member_name)`.
- When evaluated in `ExprEvaluator::eval()`:
  1. Checks if `var_name.member_name` is a direct hierarchical net identifier.
  2. If not, evaluates the aggregate vector value of `var_name`.
  3. Resolves the `PackedStructType` associated with `var_name`.
  4. Retrieves member `sm` from `PackedStructType`.
  5. Extracts the 4-state slice `[sm->offset + sm->width - 1 : sm->offset]` preserving both data (`aval`) and unknown (`bval`) bitplanes.

### C. Concurrent Non-Blocking Assignment (NBA) Slice Updates
- Non-blocking assignments to struct members (`tx_pkt.src_id <= rx_pkt.dst_id;`, `tx_pkt.dst_id <= rx_pkt.src_id;`, `tx_pkt.payload <= rx_pkt.payload + 8'h01;`) can occur concurrently in the same clocked process.
- Extended `NBAUpdate` and scheduler queue:
  ```cpp
  struct NBAUpdate {
      size_t net_id;
      LogicVal val;
      uint32_t offset = 0;
      uint32_t slice_width = 0;
      bool is_slice = false;
  };
  ```
- When committing NBA updates in `StratifiedScheduler::commit_nba_updates()`:
  - If `is_slice` is true, only the bit-range `[offset + slice_width - 1 : offset]` of the target net is mutated.
  - Concurrent sibling field updates merge cleanly into the aggregate vector without clobbering one another.

## 3. Key Architectural Achievements & Refactorings

### A. Frontend Lexer & AST Grammar
- **Tokens (`lexer.hpp`, `lexer.cpp`)**:
  - Added `TOKEN_STRUCT` (`struct`) and `TOKEN_PACKED` (`packed`).
- **AST Nodes (`ast_expr.hpp`, `ast_module.hpp`, `ast_stmt.hpp`)**:
  - Added `StructMemberNode` and `StructTypeNode` in `ast_module.hpp`.
  - Added `MemberAccessNode` in `ast_expr.hpp`.
  - Extended `TypedefNode` with `std::shared_ptr<StructTypeNode> struct_type`.
- **Parser (`parser_module.cpp`, `parser_expr.cpp`, `parser_stmt.cpp`)**:
  - Extended `Parser::parse_typedef()` to parse `typedef struct packed { ... } name;`.
  - Added struct typedef variable declaration support in module bodies and procedural scopes (`VarDeclStatementNode`).
  - Disambiguated `ident.field` member access from `ident.method()` calls in `parse_primary()`.

### B. Kernel Elaborator & Netlist Binding (`elaborator.hpp`, `elaborator.cpp`, `engine.hpp`, `engine.cpp`)
- Populated `struct_types` and `var_to_struct_type` during hierarchical module elaboration.
- Computed member bit offsets from LSBs.
- Updated `resolve_target_net_id()` to resolve member target names (`tx_pkt.src_id` -> net `tx_pkt`) for process exclusivity and ICPD checks.

### C. Stratified Scheduler & Evaluators (`scheduler.hpp`, `scheduler.cpp`, `evaluator.cpp`, `expr_evaluator.cpp`)
- Added slice update support to `NBAUpdate`, `delayed_nba_queue`, and `intra_event_nba_queue`.
- Implemented member field write logic for `BlockingAssignNode` and `NonBlockingAssignNode` across both netlist nets and local activation frames.
- Extended `CastNode` to support static casting to struct types (`packet_t'(raw_vector)`).
