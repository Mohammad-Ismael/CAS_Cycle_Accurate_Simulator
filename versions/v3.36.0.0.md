# Release v3.36.0.0: Generate Constructs 'generate for' with 'genvar', Conditional 'if-else' Generate, 'case' Generate, Hierarchical Scopes 'genblk[i]', Cross-Hierarchy Resolution, and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §27)

## 1. Overview & Milestone Scope
This release delivers **v3.36.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **72.4%** (`[███████████████████████████████████████░░░░░░░] 72.4%`) and implementing full IEEE Std 1800-2023 compliance for:
- **§27.2 - §27.6 (Generate Constructs Grammar & AST)**:
  - `generate ... endgenerate` blocks enclosing `genvar` declarations, loop generate (`for`), conditional `if-else` generate, and `case` generate.
  - `genvar` declarations: elaboration-time integer iteration variables.
  - Unrolling loop generate constructs at elaboration time using constant iteration conditions, steps (`++`, `--`, `+=`, `-=`, `=`), and variable substitutions across generated bodies.
  - Elaboration-time constant evaluation of generate conditions and case selector expressions against instance parameter bindings.
- **Hierarchical Named and Indexed Scopes (§27.5 & §27.6)**:
  - Generate block label binding creating hierarchical scopes (`gen_stages[0]`, `gen_stages[1]`, etc., or default `genblk[i]`).
  - Iterative allocation of signals, nets, processes, continuous assignments, and memory arrays within the indexed child scopes.
  - Cross-hierarchy scope resolution allowing direct upward and downward member referencing (`dut_piped.gen_stages[0].partial_accum`).
- **Continuous Assignments Driving Unpacked Array Elements**:
  - Delta-cycle scheduling and evaluation of `assign target[idx] = rhs;` continuous assignments targeting memory words.
- **Context Diagnostics & Semantic Restrictions (`[CAS-DTINPCIL]`)**:
  - Rejection of procedural assignments modifying `genvar` variables with diagnostic `[CAS-DTINPCIL]`.
  - Rejection of non-constant generate conditions during elaboration with diagnostic `[CAS-DTINPCIL]`.
