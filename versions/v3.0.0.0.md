# Release v3.0.0.0: SystemVerilog Interfaces, Interface Ports, and Hierarchical Interface Member Driving

## 1. Overview & Milestone Scope
This release delivers **v3.0.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **22.0%** and implementing full IEEE Std 1800-2023 compliance for:
- **§25 (Interfaces)**:
  - Declarations of interfaces using `interface ... endinterface` enclosing ports, internal nets, variables, and procedural logic (§25.3).
  - Elaboration-time interface instantiation (`interface_name instance_name [(connections)];`), generating a hierarchically scoped bundle of interconnect nets.
- **§25.5 (Module Interface Ports & Connections)**:
  - Modules declaring interface ports using interface identifiers as the port type (`module bus_producer (simple_bus_if bus, ...);`).
  - Hierarchical port binding: connecting an instantiated interface object to an interface port (`.bus(bus)`) binds all member signals into the module instance without manual individual pin assignments.
- **Hierarchical Interface Member Driving & Sampling**:
  - Procedural driving of interface signals from inside modules (`bus.valid <= 1'b1;`, `bus.data <= send_data;`, `bus.ready <= 1'b1;`).
  - Procedural sampling of interface signals (`if (bus.valid && bus.ready) ...`).
  - Sensitivity lists and event controls referencing interface members (`always @(posedge bus.clk or negedge rst_n)`).
  - Seamless propagation across stratified event regions (Active, NBA, Observed, Postponed) and reflection in `$monitor` and waveform dumps.

## 2. IEEE Std 1800-2023 Semantics & Mechanics

### A. Interface AST Representation (`CAS/include/frontend/ast_module.hpp`)
- Interfaces are represented via `InterfaceNode`, inheriting from `ModuleNode`:
  ```cpp
  struct InterfaceNode : public ModuleNode {
      InterfaceNode() { is_interface = true; }
  };
  ```
- Formal ports represent interface ports via `PortNode`:
  ```cpp
  struct PortNode : public ASTNode {
      ...
      bool is_interface = false;
      std::string interface_type_name = "";
  };
  ```

### B. Elaboration & Interface Port Binding (`CAS/src/kernel/elaborator.cpp`)
- When an interface is instantiated (e.g. `simple_bus_if bus (.clk(clk));`), its scope `tb_v3_0_0_0_regression.bus` is registered in `result.interface_instances`, and its ports and member signals (`clk`, `valid`, `ready`, `data`) are elaborated in `result.netlist`.
- When a module with an interface port is instantiated (e.g. `bus_producer u_producer (.bus(bus), ...);`), the elaborator detects that formal port `bus` is typed with interface `simple_bus_if`.
- The elaborator binds `child_scope + ".bus"` to the actual interface instance `tb_v3_0_0_0_regression.bus` in `result.interface_port_map`.
- Slice bindings are omitted for interface bundle ports, avoiding extraneous single-bit wire connections while preserving full member signal integrity.

### C. Unified Hierarchical Signal Resolution (`CAS/src/engine.cpp`)
- `Engine` maintains `interface_port_map` and provides `resolve_scoped_name()` and `get_net_id()`:
  ```cpp
  std::string Engine::resolve_scoped_name(const std::string& scope, const std::string& name) const {
      auto dot_pos = name.find('.');
      if (dot_pos != std::string::npos) {
          std::string prefix = name.substr(0, dot_pos);
          std::string suffix = name.substr(dot_pos + 1);
          std::string scoped_prefix = scope.empty() ? prefix : (scope + "." + prefix);

          auto it = interface_port_map.find(scoped_prefix);
          if (it != interface_port_map.end()) {
              return it->second + "." + suffix;
          }
      }
      return scope.empty() ? name : (scope + "." + name);
  }
  ```
- Evaluator (`BlockingAssignNode`, `NonBlockingAssignNode`), ExprEvaluator (`MemberAccessNode`, `IdentifierNode`), and StratifiedScheduler (sensitivity lists, event waits) query `engine.get_net_id(scope, name)` to seamlessly dispatch reads, writes, and triggers directly to the bound interface nets.

## 3. Key Architectural Achievements & Refactorings

### A. Frontend Lexer & Parser
- **Lexer (`lexer.hpp`, `lexer.cpp`)**: Added `TOKEN_INTERFACE` and `TOKEN_ENDINTERFACE` keywords.
- **Parser (`parser.hpp`, `parser.cpp`, `parser_module.cpp`, `parser_stmt.cpp`)**:
  - Added 1-token lookahead buffer (`peek_token()`) in `Parser`.
  - Parsed `interface ... endinterface` definitions.
  - Recognized interface type port declarations (`simple_bus_if bus`) and generic interface ports (`interface bus`).
  - Supported multi-dot identifier parsing in sensitivity lists (`@(posedge bus.clk)`) and procedural event controls.
  - Handled optional `modport` declarations gracefully.

### B. Kernel Elaborator & Engine
- Recorded instantiated interface instances and mapped submodule formal interface ports to bound parent interface scopes.
- Prevented interfaces from being selected as top-level root modules during automated elaboration hierarchy discovery.
- Resolved interface member targets in driver exclusivity (ICPD) checks.

### C. Stratified Scheduler & Evaluator
- Dynamically evaluated interface members in sensitivity lists across posedge/negedge clock and reset transitions.
- Dispatched non-blocking procedural assignments (`bus.valid <= 1'b1;`, `bus.ready <= 1'b1;`) directly to interface net IDs, triggering stratified NBA commits and Postponed `$monitor` sampling.
