## 1. Overview & Architectural Scope

CAS `v3.97.0.0` delivers comprehensive support for IEEE Std 1800-2023 array reduction and ordering methods across dynamic arrays and queues, with full string type preservation:
- **IEEE Std 1800-2023 §7.12.3 Array Reduction Methods**:
  - Full support for `sum`, `product`, `and`, `or`, and `xor` reduction methods on module-scope and local dynamic arrays, queues, and unpacked arrays.
  - Transparent support for both parenthesis-free method calls (`b.sum`, `b.and`, `b.or`, `b.xor`, `b.product`) and explicit parentheses (`b.sum()`, `b.product()`).
- **IEEE Std 1800-2023 §7.12.2 Array Ordering Methods**:
  - Full support for `reverse`, `sort`, and `rsort` procedural method calls on dynamic arrays and queues.
  - Native support for numerical ascending and descending sorting on integer and scalar types.
  - Lexicographical sorting and reverse ordering on `string` arrays preserving character string values and formatting (`%s`).
- **Data Type & Array Parser Enhancements**:
  - Module-level declaration parsing distinguishing dynamic arrays (`[]`), queues (`[$]`), and associative arrays (`[type]`) with explicit initializer lists.
  - Preservation of the `is_string` value attribute across dynamic array, queue push/set operations, and indexing operations.
- **Regression Suite `v3_97_0_0_array_reduction_and_ordering`**:
  - End-to-end verification covering array reductions, integer sorting, string array reversal, and string sorting, achieving 100% golden parity across CAS and Verilator.
