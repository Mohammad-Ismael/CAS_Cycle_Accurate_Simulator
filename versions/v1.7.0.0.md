# Release v1.7.0.0: Wildcard Case Evaluation (casez & casex)

## 1. Overview & Milestone Scope
This release delivers **v1.7.0.0** of the Cycle Accurate Simulator (CAS), implementing full IEEE Std 1800-2023 compliance for:
- **§12.5.1 (casez statement)**: High-impedance values (`'z'`, `'Z'`, `'?'`) in either the case expression or case item alternatives are treated as don't-care bits. Unknown values (`'x'`) are not don't-cares and must match identically.
- **§12.5.2 (casex statement)**: Unknown (`'x'`, `'X'`) and high-impedance (`'z'`, `'Z'`, `'?'`) values in either the case expression or case item alternatives are treated as don't-care bits.
- **§5.7.1 & §12.5 Syntax Compliance**: Strict rejection of illegal unbased `'?` and standalone `?` operand expressions to achieve 100% golden parity with Synopsys VCS. Based wildcard literals (e.g. `4'b????`, `1'b?`, `8'h??`) are preserved.
- **Lexical Priority & Default Resolution**: Strict top-to-bottom evaluation order with first-match execution and optional default fallthrough.
- **Comma-Separated Case Alternatives**: Multi-alternative matching per case branch.

---

## 2. Key Architecture Achievements & Refactorings

### A. Grammar & Lexical Recognition
- **Token Additions**: Added `TOKEN_CASEZ` and `TOKEN_CASEX` to `TokenType`.
- **Literal Support**: Updated `Lexer` and `NumberParser` to parse `?` wildcards within sized number literals (e.g. `4'b10??`, `4'b????`).
- **Syntax Enforcement (§5.7.1)**: Strictly restricted unbased unsized literals to `'0`, `'1`, `'z`/`'Z`, and `'x`/`'X`. Explicitly reject `'?` and bare `?` primary expressions.
- **AST Architecture**: Added `CaseType` enum (`CASE`, `CASEZ`, `CASEX`) and `match_exprs` to `CaseStatementNode` / `CaseItem` without virtual method overhead or base class bloat.

### B. High-Performance Bitwise Wildcard Matching (`LogicOps`)
- **`casez_eq`**: Implements IEEE 1800-2023 Table 12-2. Constructs care mask eliminating bits with high-Z in either operand (`dont_care = (~a_l & b_l) | (~a_r & b_r)`). Exact 4-state identity required on all remaining care bits.
- **`casex_eq`**: Implements IEEE 1800-2023 Table 12-3. Constructs care mask eliminating all 4-state unknown/high-Z bits (`dont_care = b_l | b_r`). Known value equivalence required on all remaining care bits.
- **Width Alignment**: Operands automatically zero-extended via `LogicOps::cast_width` to the maximum width of the comparison operands according to standard rules.

### C. 100% VCS Parity & Verification
- Validated on `tb_v1_7_0_0_regression` against Synopsys VCS 2025.06-SP1 golden reference.
- Verified zero regressions across all historical milestones (`v1.0.0.0` through `v1.6.0.0`).
- Parity Status: `100% VCS COMPLIANT`.
