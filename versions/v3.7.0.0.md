# Release v3.7.0.0: Functional Coverage 'covergroup', 'coverpoint', Explicit & Range 'bins', 'sample()', 'get_coverage()', '$rtoi', and Context Diagnostic '[CAS-DTINPCIL]'

## 1. Overview & Milestone Scope
This release delivers **v3.7.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **31.8%** and implementing full IEEE Std 1800-2023 compliance for:
- **§19.3 & §19.4 (Covergroup Declarations & Instantiation)**:
  - `covergroup group_identifier; ... endgroup` syntax supporting modular functional coverage specifications at module and package scopes.
  - Covergroup handle declarations (`bus_cov_cg cg_inst;`) and dynamic runtime instantiation via constructor `cg_inst = new();`.
- **§19.5 & §19.5.1 (Coverpoints, Explicit Values & Range Bins)**:
  - Explicit coverpoints declared with optional labels (`cp_cmd: coverpoint cmd_in { ... }`).
  - Discrete value bins: `bins read_cmd = {8'h01};`.
  - Contiguous interval range bins: `bins low_range = {[8'h00 : 8'h3F]};`.
  - Out-of-spec or uncovered values do not increment hit counters.
- **§19.8 (Predefined Coverage Methods: '.sample()' & '.get_coverage()')**:
  - Procedural manual sampling via `cg_inst.sample();`, triggering immediate evaluation of target expressions and bin hit counting.
  - Instance coverage querying via `cg_inst.get_coverage();`, calculating the cumulative coverage percentage across all defined coverpoints as a double-precision floating-point value (`real`).
- **IEEE Std 1800-2023 Real Datatype & '$rtoi' Built-in Conversion**:
  - Full support for `real` data types and floating-point literals (e.g. `0.0`).
  - Implementation of standard conversion function `$rtoi(real_val)` which truncates a real number to a signed 32-bit integer.
- **§19 & §21.2.3 (Dynamic Type Context Restrictions [CAS-DTINPCIL])**:
  - Continuous assignments and non-procedural `$monitor` expressions attempting to drive or monitor covergroup handles or methods are strictly illegal per IEEE 1800-2023 §19 and trigger:
    `[CAS-DTINPCIL] Dynamic type in non-procedural context: covergroup handle '...' used in continuous assignment per IEEE 1800-2023 section 19`
    `[CAS-DTINPCIL] Dynamic type in non-procedural context: covergroup handle '...' used directly in $monitor per IEEE 1800-2023 section 19 & 21.2.3`

## 2. IEEE Std 1800-2023 Semantics & Implementation Mechanics

### A. Coverage AST Nodes (`CAS/include/frontend/ast_module.hpp`, `CAS/include/frontend/ast_expr.hpp`)
- `CovergroupBinNode` stores bin identifier and set of value/range limits:
  ```cpp
  struct CovergroupBinNode : public ASTNode {
      std::string name;
      std::vector<InsideRange> ranges;
  };
  ```
- `CoverpointNode` encapsulates label, monitored expression, and list of bin definitions:
  ```cpp
  struct CoverpointNode : public ASTNode {
      std::string label;
      std::unique_ptr<ExpressionNode> target_expr;
      std::vector<std::unique_ptr<CovergroupBinNode>> bins;
  };
  ```
- `CovergroupNode` groups multiple coverpoints into a named coverage type:
  ```cpp
  struct CovergroupNode : public ASTNode {
      std::string name;
      std::vector<std::unique_ptr<CoverpointNode>> coverpoints;
      std::unordered_map<std::string, CoverpointNode*> coverpoint_map;
  };
  ```

### B. Kernel Coverage Engine (`CAS/include/common/coverage_types.hpp`)
- `CovergroupBin` evaluates values against its defined ranges:
  ```cpp
  struct CovergroupBin {
      std::string name;
      std::vector<InsideRange> ranges;
      uint64_t hit_count = 0;

      bool matches(uint64_t val, const std::function<uint64_t(ExpressionNode*)>& eval_fn) const;
  };
  ```
- `CoverpointItem` tracks bin coverage:
  ```cpp
  double get_coverage() const {
      if (bins.empty()) return 100.0;
      size_t covered = 0;
      for (const auto& b : bins) {
          if (b.hit_count > 0) covered++;
      }
      return (static_cast<double>(covered) / static_cast<double>(bins.size())) * 100.0;
  }
  ```
- `CovergroupInstance` manages heap-allocated covergroup instances, executing `.sample()` and computing composite coverage across all coverpoints:
  ```cpp
  double get_coverage() const {
      if (coverpoints.empty()) return 0.0;
      double sum = 0.0;
      for (const auto& cp : coverpoints) sum += cp.get_coverage();
      return sum / static_cast<double>(coverpoints.size());
  }
  ```

### C. Standard '$rtoi' & 'real' Floating-Point Support (`CAS/src/kernel/expr_evaluator.cpp`)
- `LogicVal` augmented with `bool is_real` and `double real_val`.
- Expression evaluator handles `$rtoi`:
  ```cpp
  if (fn_call->func_name == "$rtoi") {
      if (!fn_call->args.empty()) {
          LogicVal arg_val = eval(fn_call->args[0].get(), scope);
          int64_t ival = arg_val.is_real ? static_cast<int64_t>(arg_val.real_val)
                                         : static_cast<int64_t>(arg_val.aval);
          return LogicVal::make_known(32, static_cast<uint64_t>(ival));
      }
      return LogicVal::make_known(32, 0);
  }
  ```
