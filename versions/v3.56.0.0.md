## 1. Overview & Architectural Scope

CAS `v3.56.0.0` introduces full standard support for **IEEE Std 1800-2023 §7.12.1 – §7.12.4** array reduction methods:
- Array reduction methods `sum`, `product`, `and`, `or`, and `xor` across dynamic arrays, fixed unpacked arrays, associative arrays, and queues.
- Optional `with ( expression )` iterator clauses evaluating per-element transformation expressions before reduction.
- Default iterator variable `item` and user-specified explicit iterator argument (e.g., `arr.sum(x) with (x > 5)`).
- 4-state unknown propagation conforming to IEEE Std 1800-2023 arithmetic and bitwise rules (unknown operands produce X for arithmetic sum/product; bit-by-bit 4-state logic for and, or, xor).
- Empty array neutral return values (1 for product, 0 for sum/and/or/xor) with element width and signedness.
- Context diagnostics `[CAS-DTINPCIL]` enforcing at most one iterator argument and rejecting reduction method calls on non-array targets.

## 2. Key Language & Kernel Features

### A. Grammar & Method Syntax (§7.12)
```systemverilog
arr.sum()
arr.sum() with ( expression )
arr.sum( iterator_id ) with ( expression )
arr.product()
arr.product() with ( expression )
arr.and()
arr.and() with ( expression )
arr.or()
arr.or() with ( expression )
arr.xor()
arr.xor() with ( expression )
```

### B. Iterator Binding & Execution Context
- If no argument is provided in the method call parentheses, the iterator identifier defaults to `item`.
- An explicit iterator identifier may be supplied as the single argument to the method call (`arr.sum(x) with (x * 2)`).
- Each element evaluation creates an execution frame binding the iterator symbol with the array element width, signedness, and value.
- Chained member access (e.g. `dut.history_buffer.sum() with (...)`) and class member arrays are seamlessly supported.

### C. 4-State Unknown Propagation Semantics
- Arithmetic methods (`sum`, `product`): if any bit of the accumulator or the operand contains an unknown state (`x` or `z`), the result is all `x`'s across the target bit width.
- Bitwise reduction methods (`and`, `or`, `xor`): evaluated bit-by-bit according to IEEE Std 1800-2023 4-state truth tables (`0 & x = 0`, `1 | x = 1`, `x ^ x = x`).

### D. Diagnostics & Strict Standards Compliance (`[CAS-DTINPCIL]`)
- Arity check:
  ```text
  [CAS-DTINPCIL] Array reduction method '<method>' accepts at most one iterator argument per IEEE 1800-2023 section 7.12
  ```
- Target validation check:
  ```text
  [CAS-DTINPCIL] Array reduction method '<method>' called on non-array target '<var_name>' per IEEE 1800-2023 section 7.12
  ```
