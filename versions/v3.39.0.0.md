**Release Date:** November 2026

## 1. Overview & Capabilities
Milestone v3.39.0.0 implements native support for IEEE Std 1800-2023 §14.11, §14.13, and §14.16, providing complete clocking block skew timing mechanics, `#1step` Preponed region sampling isolation from Active/NBA updates, delayed output skew drives, naked cycle delay statements (`##N`), and default clocking declarations (`default clocking cb;`).

### Key Features Implemented:
1. **Default Clocking Declarations (§14.12)**:
   - Added AST support for `DefaultClockingNode` and module-level `default_clocking_name`.
   - Parsed `default clocking <cb_name>;` alongside inline named (`default clocking cb @(...);`) and unnamed (`default clocking @(...);`) clocking blocks in `Parser::parse_all()`.
   - Bound default clocking in `elaborator.cpp` via `result.default_clocking_map[scope] = cb_idx`.
   - Enforced context diagnostic `[CAS-DTINPCIL] [CAS-DCNS]` if cycle delay `##N` is used in a scope without a specified default clocking block.

2. **Cycle Delay Operator `##N` (§14.11)**:
   - Handled `CycleDelayStatementNode` in procedural processes and task activation frames in `scheduler.cpp`.
   - Bound thread suspension to `N` primary clocking events of the in-scope default clocking block.
   - Decremented cycle counters and resumed suspended threads into the Active/Reactive region upon completion of `N` clocking events.

3. **Input Skew Sampling & `#1step` Preponed Region Isolation (§14.13, §14.14)**:
   - Stratified scheduler captures `preponed_net_values` at the beginning of each simulation time-slot prior to processing Active events or clock edge transitions.
   - Input signals declared with `#1step` skew sample directly from `preponed_net_values`, guaranteeing total isolation from concurrent NBA updates occurring within the same time-slot.
   - Fixed explicit skews (`input #delay`) sample from `net_time_history` at `T_clk - skew`.

4. **Output Skew Drives (§14.16)**:
   - Evaluated clocking block output assignments `cb.signal <= expr;` respecting signal direction.
   - Prohibited driving `input` clocking signals with context diagnostic `[CAS-DTINPCIL]`.
   - Calculated target drive time as `T_clk + output_skew_ticks` scaled by timescale ratio; scheduled non-blocking updates via `StratifiedScheduler::queue_delayed_nba()` or immediate `queue_nba()` when skew is 0.
   - Buffered asynchronous drives executed prior to the clock edge inside `pending_drives` to commit at the next clocking event plus output skew.
