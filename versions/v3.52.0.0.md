## 1. Overview & Capabilities
Milestone v3.52.0.0 implements complete support for IEEE Std 1800-2023 §20.9 bit count system function `$countbits`, providing multi-predicate 4-state counting across `'0`, `'1`, `'x`, and `'z` control bits on arbitrary integral and packed bit-vectors. The function operates in elaboration-time constant evaluation (parameter declarations, localparams, ranges), continuous assignments, and runtime procedural statements with context diagnostic enforcement `[CAS-DTINPCIL]`.

### Key Features Implemented:
1. **Multi-Predicate 4-State Bit Counting (§20.9, Table 20-7)**:
   - Syntax:
     ```systemverilog
     $countbits ( expression , control_bit { , control_bit } )
     ```
   - Evaluates the bit-vector `expression` bit by bit across its defined bit width.
   - For each bit position, tests membership against the set of scalar control bits specified in arguments 2 through 5:
     * `'0` / `1'b0`: matches bits with logic value 0 (`aval == 0, bval == 0`).
     * `'1` / `1'b1`: matches bits with logic value 1 (`aval == 1, bval == 0`).
     * `'x` / `1'bx`: matches unknown bits (`aval == 1, bval == 1`).
     * `'z` / `1'bz`: matches high-impedance bits (`aval == 0, bval == 1`).
   - Bit 0 of each control expression defines the match criteria; duplicate or redundant control bits are merged cleanly into matching masks.
   - Returns a 32-bit unsigned integer count of all bits matching any of the specified control bit predicates.

2. **Elaboration-Time Constant Evaluation & Sizing**:
   - Parameter assignments: `parameter int KNOWN_COUNT = $countbits(RESET_VECTOR, '0, '1);`
   - Evaluated in `Parser::eval_const_expr_with_params` and `Elaborator::eval_const_expr`.
   - Genvar substitution and AST cloning in `substitute_genvar_in_expr`.

3. **Runtime Procedural & Continuous Evaluation**:
   - Supports static and dynamic evaluation in procedural blocks (`always`, `initial`, tasks, functions) and continuous assignments (`assign`).
   - Supports 2-state and 4-state vectors (`logic`, `bit`, `reg`, `wire`, packed structures, packed arrays).

4. **Context Diagnostics (`[CAS-DTINPCIL]`)**:
   - Enforces argument count bounds (between 2 and 5 arguments inclusive):
     * Less than 2 arguments:
       `[CAS-DTINPCIL] $countbits requires between 2 and 5 arguments per IEEE 1800-2023 section 20.9`
     * More than 5 arguments:
       `[CAS-DTINPCIL] $countbits requires between 2 and 5 arguments per IEEE 1800-2023 section 20.9`
   - Rejects non-integral target or control expressions (such as class handles, chandles, strings, reals, unpacked arrays):
     * `[CAS-DTINPCIL] Non-integral argument '<var>' passed to $countbits per IEEE 1800-2023 section 20.9`
     * `[CAS-DTINPCIL] Non-integral argument passed to $countbits per IEEE 1800-2023 section 20.9`
