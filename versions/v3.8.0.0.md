# Release v3.8.0.0: Functional Cross Coverage 'cross', Multi-Dimensional Cartesian Bin Generation, Joint Sampling, Composite Coverage Calculation, and Diagnostic '[CAS-DTINPCIL]'

## 1. Overview & Milestone Scope
This release delivers **v3.8.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **33.2%** and implementing full IEEE Std 1800-2023 compliance for:
- **§19.6 (Cross Coverage Declarations)**:
  - `[cross_identifier :] cross cp1, cp2, ... ;` syntax inside `covergroup ... endgroup`.
  - Supports crossing two or more previously declared coverpoints within the same covergroup.
- **§19.6.1 (Cartesian Product Bin Allocation)**:
  - Automatic generation of the multi-dimensional Cartesian product of bins across all participating coverpoints.
  - For $N$ coverpoints with bin counts $B_1, B_2, \dots, B_N$, the cross item generates $\prod_{k=1}^N B_k$ unique Cartesian cross bins.
- **§19.6.2 & §19.8 (Joint Cross Sampling & Composite Coverage Calculation)**:
  - During `cg.sample()`, the runtime identifies which bin was hit for each coverpoint and matches the corresponding Cartesian tuple bin $\langle b_1, b_2, \dots, b_N \rangle$, incrementing its hit count.
  - Instance coverage calculation `cg.get_coverage()` computes the composite weighted average across all $N$ coverpoints and $M$ cross items:
    $$\text{Coverage} = \frac{\sum_{i=1}^N \text{Cov}_{cp, i} + \sum_{j=1}^M \text{Cov}_{cross, j}}{N + M}$$
- **§19 & §21.2.3 (Dynamic Type Context Restrictions [CAS-DTINPCIL])**:
  - Enforces strict prohibition of cross identifiers or covergroup member accesses in continuous assignments and `$monitor` expressions.


### B. Parser Support (`CAS/src/frontend/parser_module.cpp`)
- `parse_covergroup()` parses cross items:
  ```systemverilog
  cross_label: cross cp_a, cp_b;
  ```
- Validates participating coverpoint identifiers against already declared coverpoints and builds the `CoverCrossNode`.

### C. Kernel Cross Coverage Engine (`CAS/include/common/coverage_types.hpp`, `CAS/include/engine.hpp`)
- `CoverCrossBin` tracks hit counts for a specific multidimensional bin tuple:
  ```cpp
  struct CoverCrossBin {
      std::vector<size_t> bin_indices; // indices into participating coverpoints' bins
      uint64_t hit_count = 0;
  };
  ```
- `CoverCrossItem` manages Cartesian product generation and cross coverage metrics:
  ```cpp
  struct CoverCrossItem {
      std::string name;
      std::vector<std::string> coverpoint_names;
      std::vector<size_t> crossed_cp_indices;
      std::vector<CoverCrossBin> cross_bins;

      void generate_cartesian(const std::vector<CoverpointItem>& cps);
      double get_coverage() const;
  };
  ```
- Recursive Cartesian generator:
  ```cpp
  void generate_cartesian(const std::vector<CoverpointItem>& cps) {
      cross_bins.clear();
      std::vector<size_t> current_tuple;
      std::function<void(size_t)> recurse = [&](size_t cp_idx) {
          if (cp_idx == crossed_cp_indices.size()) {
              CoverCrossBin b;
              b.bin_indices = current_tuple;
              b.hit_count = 0;
              cross_bins.push_back(b);
              return;
          }
          size_t actual_cp = crossed_cp_indices[cp_idx];
          size_t num_bins = cps[actual_cp].bins.size();
          for (size_t b = 0; b < num_bins; ++b) {
              current_tuple.push_back(b);
              recurse(cp_idx + 1);
              current_tuple.pop_back();
          }
      };
      recurse(0);
  }
  ```
- Composite coverage calculation in `CovergroupInstance::get_coverage()`:
  ```cpp
  double get_coverage() const {
      size_t total_items = coverpoints.size() + crosses.size();
      if (total_items == 0) return 0.0;
      double sum = 0.0;
      for (const auto& cp : coverpoints) {
          sum += cp.get_coverage();
      }
      for (const auto& cx : crosses) {
          sum += cx.get_coverage();
      }
      return sum / static_cast<double>(total_items);
  }
  ```
