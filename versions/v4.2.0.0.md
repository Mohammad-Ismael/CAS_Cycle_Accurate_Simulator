## 1. Release Overview & Scope

CAS `v4.2.0.0` delivers comprehensive IEEE Std 1800-2023 compliance across **Chapters 20, 21, 22, 23, 24, 25, and 26**, achieving **100.0% execution parity (69/69 passing simulation tests in Chapters 20–26)** in the industry-standard `sv-tests` conformance suite. Combined with Chapters 5–15 (171/171), CAS now achieves **100.0% compliance across 240 tests (Chapters 5–15 & Chapters 20–26)**, leaving only Chapter 16 (SVA) and Chapter 18 (Constrained Random) remaining on the full LRM roadmap. In addition, `v4.2.0.0` incorporates **102 consecutive milestone regression test suites (`v1.0.0.0` through `v4.2.0.0`)**.

### Key Capabilities Delivered in v4.2.0.0:
- **IEEE Std 1800-2023 §26.3 Packages & Sticky Formal Port Types**:
  - Full sticky formal port data type inheritance across subroutine definitions in packages, tasks, and functions (`function int add(int a, b);` properly gives `b` data type `int`).
- **IEEE Std 1800-2023 §20.5, §20.6, §20.8, §20.9 System Functions**:
  - Real conversion functions: `$itor`, `$realtobits` / `$bitstoreal`.
  - IEEE 1800-2023 32-bit single-precision floating point: `shortreal` declaration and bit conversion functions `$shortrealtobits` / `$bitstoshortreal`.
  - Unbounded parameters and queries: `parameter int P = $;` and `$isunbounded(...)`.
  - Procedural parameter declarations in `initial`/`always` blocks with `$isunknown(...)`.
  - Standard mathematical system functions: `$ceil`, `$floor`, `$exp`, `$ln`, `$log10`, `$pow`, `$sqrt`, and trigonometric functions.
- **IEEE Std 1800-2023 §21.2, §21.3 Display/Monitor, Radix Tasks & File I/O**:
  - Formatless `$display(...)` and `$monitor(...)` where the first argument is a generic value expression rather than a string literal format string.
  - Base radix system tasks: `$displayb`, `$displayo`, `$displayh`, `$monitorb`, `$monitoro`, `$monitorh`.
  - Monitor control tasks: `$monitoron` and `$monitoroff`.
  - Standard C `FILE*` file I/O runtime: `$fopen`, `$fclose`, `$fwrite`, `$fflush`.
  - File positioning and queries: `$ftell(fd)`, `$fseek(fd, offset, op)`, `$rewind(fd)`, `$feof(fd)`, `$ferror(fd, str)`.
  - Character I/O: `$ungetc(c, fd)` and `$fgetc(fd)`.
  - String formatted input parsing: `$sscanf(str, format, ...)` both as procedural statement and system function with variable write-back.
