## 1. Release Overview & Scope

CAS `v4.3.5.0` achieves **100.0% compliance across all 412 Positive Default Elaboration / Parsing tests and all 644 Positive Chapter Tests in the entire IEEE Std 1800-2023 `sv-tests` benchmark suite** across Chapters 5 through 26. The regression test suite advances to **111/111 passing milestone suites** with 100% VCS and Verilator golden parity.

### Key Capabilities Delivered in v4.3.5.0:
- **Procedural `do-while` Loop Execution (IEEE Std 1800-2023 §12.7.2)**:
  - Added `TOKEN_DO`, `DoWhileStatementNode` AST node, parser support for `do <stmt> while (<expr>);`, and simulation runtime evaluation in `evaluator.cpp`.
- **Concatenation Part-Selects & Slices (IEEE Std 1800-2023 §11.4.12)**:
  - Added AST and parser support for part-select directly indexed on concatenation expressions (`{in_a, in_b}[11:4]`).
  - Added slice evaluation in `expr_evaluator.cpp`, AST cloning support in `elaborator.cpp`, and JIT bytecode compiler fallback.
- **Implicit Net Ingestion in Elaboration (IEEE Std 1800-2023 §6.10)**:
  - Extended elaborator to synthesize implicit 1-bit wire nets for undeclared identifiers encountered in continuous assignment targets and slice expressions.
- **Procedural Event Controls & Qualifiers (IEEE Std 1800-2023 §9.4.2)**:
  - Supported `edge` and `iff <expr>` event controls in procedural sensitivity lists (`@(posedge clk iff en)`).
  - Supported hierarchical event trigger expressions (`-> top.e;` and `->> top.e;`).
  - Supported `repeat(expr) @(...)` intra-assignment event controls.
- **Lexical, Keyword & Numeric Syntax Enhancements (IEEE Std 1800-2023 §5)**:
  - Floating-point scientific notation parsing (`1.0e-3`, `2.5E+4`).
  - Standard time literals with unit suffixes (`fs`, `ps`, `ns`, `us`, `ms`, `s`).
  - Compiler directives `` `begin_keywords `` and `` `end_keywords ``.
  - Attribute skipping `(* ... *)` in whitespace/comment scanner, cleanly distinguishing attribute blocks from `(*)` wildcards.
- **Declarations, Types & Net Modifiers (IEEE Std 1800-2023 §6)**:
  - Added `TOKEN_SPECPARAM`, `TOKEN_INTERCONNECT`, `TOKEN_NETTYPE`.
  - Added user-defined nettype definitions with resolution functions (`nettype real real_net with real_sum;`).
  - Added `specparam` timing specifications and net delay parsing (`wire #10 w;`, `wire #(1:2:3) w;`).
  - Added `tri0`, `tri1`, `triand`, `trior`, `supply0`, `supply1`, `uwire`, `time`, `realtime`.
  - Added type parameter declarations (`parameter type T = int`, `localparam type T = logic [7:0]`).
  - Added anonymous enum variable declarations (`enum [type] { ... } a, b;`) and enum range sequences (`name[N]`, `name[N:M]`).
- **Classes, Interfaces & Pattern Matching (IEEE Std 1800-2023 §8, §12)**:
  - Relaxed interface class implementation check so abstract `virtual` classes can partially implement interface class methods without premature diagnostics.
  - Added object shallow copy syntax `new source_obj;`.
  - Added `matches` pattern matching operator in relational expressions.
  - Distinquished declaration initializers (`logic a = 0;`) from procedural multiple drivers in ICPD checks.
