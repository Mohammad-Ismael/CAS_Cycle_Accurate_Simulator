## 1. Release Overview & Scope

CAS `v4.2.2.0` delivers comprehensive IEEE Std 1800-2023 §18.17 random sequence generation (`randsequence ... endsequence`), completing **100.0% execution parity (14/14 tests)** across **Chapter 18 (Constrained Randomization)**. Combined with Chapters 5–15 (171/171) and Chapters 20–26 (69/69), CAS now achieves **100.0% compliance across 254 simulation tests** in the industry-standard `sv-tests` suite. In addition, `v4.2.2.0` incorporates **104 consecutive milestone regression test suites (`v1.0.0.0` through `v4.2.2.0`)**.

### Key Capabilities Delivered in v4.2.2.0:
- **IEEE Std 1800-2023 §18.17 Random Sequence Generation (`randsequence`)**:
  - Full lexer, grammar, and AST support for `TOKEN_RANDSEQUENCE ... TOKEN_ENDSEQUENCE` and `TOKEN_COLON_EQ` (`:=`).
  - Sequential productions (`main : first second done;`) with recursive production rule dispatch.
  - Production alternatives and weighted branch selection (`first := 1 | second := 0;`) with zero-weight exclusion.
  - Production control statements:
    - Conditional production branching: `if (cond) prodA else prodB;`
    - Selection production branching: `case (expr) val: prod; default: prod; endcase;`
    - Repetitive production branching: `repeat (count) prod;`
  - Interleaving productions with `rand join [(prob)] prodA prodB;` executing production items in random or probability-weighted order.
  - Production value passing (§18.17.7): formal arguments and return types on production rules (`void add(int y) : { x = x + y; };`), evaluated in a child scope frame while preserving outer variable visibility and mutability.
  - Aborting production semantics (§18.17.6):
    - `break` inside an action block immediately terminates the entire `randsequence` statement.
    - `return` inside an action block terminates only the current production rule, allowing caller productions to resume and complete.
