## 1. Release Overview & Scope

CAS `v4.2.1.0` implements IEEE Std 1800-2023 §18.16 random weighted case statement (`randcase ... endcase`), procedural `static` variable declarations and lifetime persistence (§6.21 / §13.3), and compilation-unit ($unit / file-level) task and function elaboration and execution.

### Key Capabilities Delivered in v4.2.1.0:
- **IEEE Std 1800-2023 §18.16 Random Weighted Case (`randcase`)**:
  - Full lexer, grammar, and AST support for `TOKEN_RANDCASE ... TOKEN_ENDCASE`.
  - Non-negative branch weight evaluation (`weight: statement`).
  - Zero-weight branch elimination and uniform selection proportional to positive branch weights.
  - Elaboration and constant evaluation support for `randcase` inside constant functions (`eval_const_stmt`).
- **IEEE Std 1800-2023 §6.21 & §13.3 Procedural `static` Variables**:
  - Parser support for procedural `static` variable declarations inside subroutines and blocks.
  - Execution context and scheduler persistence across subroutine invocations: initial value evaluated only once upon first invocation, state preserved across repeated calls.
  - Support for static variables in functions, automatic/static tasks, and procedural initial/always blocks.
- **IEEE Std 1800-2023 §3.12 Compilation-Unit Subroutines**:
  - Full parsing and global symbol table tracking (`Parser::global_functions`, `Parser::global_tasks`) for non-scoped file-level subroutines.
  - Automatic elaboration into netlist function and task maps with root visibility (`$root.<name>`, `$unit::<name>`, and unqualified `<name>`).
