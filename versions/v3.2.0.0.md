# Release v3.2.0.0: Clocking Blocks, Default Clocking, Cycle Delay '##N', Preponed Sampling, and Diagnostic '[CAS-DCNS]'

## 1. Overview & Milestone Scope
This release delivers **v3.2.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **24.8%** and implementing full IEEE Std 1800-2023 compliance for:
- **§14 (Clocking Blocks)**:
  - Declarations of clocking blocks (`clocking clocking_identifier @( event_expression ); ... endclocking`) enclosing signal direction lists and skews (§14.3).
  - Default clocking block designation (`default clocking cb @(posedge clk);`) establishing the default clock domain for declaring scopes (§14.12).
  - Skew specifications (`default input #1step output #0;`) and per-signal skews.
- **§14.11 (Cycle Delay Operator '##N')**:
  - Procedural cycle delay statements (`##N;` and `##(expr);`) suspending processes across integer clocking events of the default clocking block.
  - Multi-cycle delays (e.g. `##2;`) advancing across multiple clock edges accurately.
  - Non-positive cycle delays (`##0`) completing without process suspension per IEEE 1800-2023 §14.11.
- **Diagnostic [CAS-DCNS]**:
  - Enforced compilation/elaboration rule matching Synopsys VCS `Error-[DCNS]`:
    `"[CAS-DCNS] Default clocking not specified: Cycle delay operator requires a default clocking to be specified."`
- **§14.13 & §14.16 (Preponed Input Sampling & Synchronous Output Drives)**:
  - `#1step` input skew sampling captured in the Preponed region immediately prior to the clocking event.
  - Clocking block reads (`cb.signal`) returning the Preponed sampled value.
  - Synchronous clocking block output drives (`cb.signal <= expr;`) synchronized to the clocking event, scheduling updates in the NBA region and preventing zero-time race conditions.

## 2. IEEE Std 1800-2023 Semantics & Mechanics

### A. Clocking AST & Type Representation (`CAS/include/common/clocking_types.hpp`, `ast_module.hpp`, `ast_stmt.hpp`)
- `ClockingBlockNode` represents parsed clocking blocks in the module/interface AST:
  ```cpp
  struct ClockingItem {
      std::string direction; // "input", "output", "inout"
      std::string signal_name;
      std::string skew = "";
  };

  struct ClockingBlockNode : public ASTNode {
      std::string name;
      bool is_default = false;
      EdgeType clock_edge = EdgeType::POSEDGE;
      std::string clock_signal;
      std::string default_input_skew = "1step";
      std::string default_output_skew = "0";
      std::vector<ClockingItem> items;
      std::unordered_map<std::string, ClockingItem> item_map;
  };
  ```
- `CycleDelayStatementNode` models `##N` procedural statements:
  ```cpp
  struct CycleDelayStatementNode : public StatementNode {
      std::unique_ptr<ExpressionNode> cycle_expr;
      std::string clocking_name;
  };
  ```
- Runtime kernel structures in `clocking_types.hpp`:
  ```cpp
  struct ClockingSignalInfo {
      std::string direction;
      std::string signal_name;
      size_t net_id = (size_t)-1;
      std::string skew = "";
      LogicVal sampled_value; // Preponed sampled value
  };

  struct ClockingBlockInstance {
      std::string name;
      std::string scope;
      bool is_default = false;
      EdgeType clock_edge = EdgeType::POSEDGE;
      std::string clock_signal;
      size_t clock_net_id = (size_t)-1;
      std::unordered_map<std::string, ClockingSignalInfo> signals;
      std::vector<ClockingPendingDrive> pending_drives;
  };
  ```

### B. Elaboration & Diagnostic [CAS-DCNS] Enforcement (`CAS/src/kernel/elaborator.cpp`)
- During elaboration, all processes, tasks, and blocks are inspected for `CycleDelayStatementNode`.
- If a cycle delay statement references no explicit clocking block and no default clocking block is defined in scope, elaboration halts with:
  `"[CAS-DCNS] Default clocking not specified: Cycle delay operator requires a default clocking to be specified."`
- Elaborator binds clocking signals to netlist nets and registers default clocking domains in `default_clocking_map`.

### C. Stratified Scheduler Integration (`CAS/src/kernel/scheduler.cpp`)
- `StratifiedScheduler::evaluate_clocking_blocks()` runs alongside sequential blocks in the active delta loop:
  1. Detects clock edges (`net.is_posedge()`, `net.is_negedge()`).
  2. Samples inputs into shadow buffers in the Preponed phase before active updates commit.
  3. Commits pending asynchronous drives into the NBA region.
  4. Decrements `cycle_delay_count` on all suspended processes (`is_waiting_cycle = true`). When remaining cycles hit 0, processes are unblocked and resumed in the Active region.
- Member accesses (`cb.data_out`) resolve through `expr_evaluator.cpp` to the Preponed sample buffer.
- Synchronous output drives (`cb.valid_in <= expr`) queue NBA updates either immediately (if active at the clock edge) or into `pending_drives` to commit at the next clock edge.
