## 1. Overview & Architectural Scope

CAS `v3.53.0.0` introduces full specification support for **IEEE Std 1800-2023 §20.7** array dimension query system functions:
- `$dimensions(a)` returns the total number of dimensions in an array variable or array data type (unpacked dimensions plus packed dimensions).
- `$unpacked_dimensions(a)` returns the number of unpacked dimensions in an array variable or array data type.
- Support for introspection across singular and multi-dimensional fixed-size packed bit-vectors, multi-dimensional unpacked arrays, packed structures, user-defined `typedef` declarations (including multi-bracket packed dimensions and unpacked array typedefs), and primitive data types with vector ranges (`logic [7:0][3:0]`).
- Constant-folding at elaboration time allowing `$dimensions` and `$unpacked_dimensions` to size module parameter defaults, localparams, and signal vector ranges.
- Context-sensitive diagnostic enforcement `[CAS-DTINPCIL]` rejecting 0 or multiple arguments, and prohibiting invocation on non-array / scalar data types (such as scalar 1-bit `logic`).

## 2. Key Language & Kernel Features

### A. Grammar & Syntax (§20.7, Table 20-4, Syntax 20-3)
```systemverilog
$dimensions ( array_identifier_or_type )
$unpacked_dimensions ( array_identifier_or_type )
```
Both functions take exactly one argument: either an array variable / signal identifier or an array data type (including user-defined typedef names and built-in type keywords with dimension qualifiers).

### B. Dimension Calculation Rules
1. **Total Dimensions (`$dimensions`)**:
   - For an array with $U$ unpacked dimensions and $P$ packed dimensions, `$dimensions` returns $U + P$.
   - Any multi-bit vector (`logic [N:0]`, `bit [N:0]`) contributes 1 packed dimension.
   - Multi-dimensional packed arrays (e.g. `logic [7:0][7:0]`) contribute $P$ packed dimensions.
   - Packed structs contribute 1 packed dimension.
2. **Unpacked Dimensions (`$unpacked_dimensions`)**:
   - Returns $U$, the number of unpacked dimensions in the array.
   - A pure packed vector or packed struct returns `0`.
   - Memories, unpacked structures, and multidimensional unpacked arrays return their respective unpacked rank.

### C. Elaboration-Time Constant Folding
Expressions involving `$dimensions` and `$unpacked_dimensions` applied to typedefs or statically-sized signals fold to unsigned 32-bit constants during AST constant evaluation, enabling direct usage in:
```systemverilog
localparam int D_TOTAL = $dimensions(frame_buf_t);
localparam int D_UNPKD = $unpacked_dimensions(frame_buf_t);
logic [D_TOTAL-1:0] total_dim_bus;
logic [D_UNPKD-1:0] unpkd_dim_bus;
```

### D. Context Diagnostic Enforcement (`[CAS-DTINPCIL]`)
- Arity validation: Zero arguments or $\ge 2$ arguments trigger:
  `[CAS-DTINPCIL] <func> requires exactly one argument per IEEE 1800-2023 section 20.7`
- Non-array scalar operand rejection: Invoking on scalar 1-bit variables (`logic s; $dimensions(s)`) triggers:
  `[CAS-DTINPCIL] Illegal first argument to array query system function; please pass an array identifier or array data type`
