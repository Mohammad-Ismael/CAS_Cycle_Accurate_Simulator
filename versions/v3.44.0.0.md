## 1. Overview & Capabilities
Milestone v3.44.0.0 implements complete support for IEEE Std 1800-2023 §6.24.1 static cast operators, enabling compile-time and runtime type conversion, size truncation/extension, sign coercion, enum coercion, and packed structure casting across expressions and assignments.

### Key Features Implemented:
1. **Static Cast Grammar & Forms (§6.24.1)**:
   - Sized casting: `constant_primary '( expression )` (e.g. `16'(expr)`, `8'(expr)`, `(width)'(expr)`).
   - Sign casting: `signed'( expression )` and `unsigned'( expression )` converting the signing attribute of integral expressions.
   - Built-in type casting: `logic'(expr)`, `bit'(expr)`, `int'(expr)`, `integer'(expr)`, `real'(expr)`.
   - User-defined type & typedef casting: `type_identifier '( expression )` and package-scoped `package_name::type_identifier '( expression )`.

2. **Casting Semantics & Type Coercion**:
   - **Size Casting (`size'(expr)`)**: Resizes the evaluated bit-vector to the specified target bit width. If the target size exceeds the expression width, extends unsigned values with zeros or signed values with the sign bit; if smaller, truncates the most significant bits (MSB truncation) preserving LSBs.
   - **Sign Casting (`signed'` / `unsigned'`)**: Sets or clears the signedness attribute on the underlying `LogicValue`, ensuring downstream operations (such as outer size casts or arithmetic comparisons) perform correct sign-extension.
   - **Enumeration Type Coercion**: Permits casting arbitrary integer or bit-vector expressions to an enumerated type (`opcode_e'(raw_data)`), preserving the bit-vector value even when out of declared enumeration range.
   - **Packed Structure Static Casting**: Converts contiguous bit-vector expressions into the packed struct layout (`word_st'(data)`), supporting bit slicing, field access, and truncation/zero-extension.

3. **Context Diagnostic Enforcement (`[CAS-DTINPCIL]`)**:
   - Enforces that size cast bit-widths must be strictly positive integers ($\ge 1$). Zero or negative bit widths (e.g., `0'(expr)`, `-4'(expr)`, `(-4)'(expr)`) immediately raise:
     `[CAS-DTINPCIL] Size cast bit width must be positive integer (got <width>) per IEEE 1800-2023 section 6.24.1`.
   - Enforces that type identifiers used in static cast expressions must refer to defined types or typedefs. Unresolved type names raise:
     `[CAS-DTINPCIL] Undefined or unresolved type identifier in static cast per IEEE 1800-2023 section 6.24.1: '<name>'`.
