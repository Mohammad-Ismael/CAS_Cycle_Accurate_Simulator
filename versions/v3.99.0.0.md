## 1. Overview & Architectural Scope

CAS `v3.99.0.0` delivers full compliance with IEEE Std 1800-2023 §7.8 & §7.9 associative array semantics and §7.12.1 array locator methods across arbitrary array types:
- **IEEE Std 1800-2023 §7.9 Associative Array Traversal Methods**:
  - Full support for `first(index)`, `last(index)`, `next(index)`, and `prev(index)` traversal methods modifying the target key index variable in place and returning integer status (`1` on success, `0` when no further keys exist).
  - Proper ordered traversal across string, integer, and custom key spaces conforming to canonical lexical and numerical ordering.
- **IEEE Std 1800-2023 §7.12.1 Array Locator Methods**:
  - Comprehensive implementation of `.max()`, `.min()`, `.unique()`, and `.unique_index()` locator methods for associative arrays, dynamic arrays, queues, and unpacked arrays.
  - Return of queues containing extreme or deduplicated elements / traversal indices (`qi = arr.max()`, `qi = arr.min()`, `qi = arr.unique()`, `qi = arr.unique_index()`).
- **IEEE Std 1800-2023 §7.8 & §7.9.1 Type Support, Defaults & Subroutine Passing**:
  - Transparent parser and elaborator support for class types, structs, and custom user-defined typedefs as associative array keys (`int arr [ C ];`, `int arr [ Unpkt ];`).
  - Associative array default value initialization via array patterns (`'{default: "hello"}`).
  - Full support for passing associative arrays as subroutine arguments by value and by reference with automatic type matching and element mutation persistence.
- **Regression Suite `v3_99_0_0_associative_arrays_traversal_and_locators`**:
  - End-to-end verification covering associative array traversal (`first`, `last`, `next`, `prev`), array locators (`max`, `min`, `unique`, `unique_index`), default pattern assignments, class/struct key declarations, and subroutine argument passing, achieving 100% golden parity across CAS and Verilator.
