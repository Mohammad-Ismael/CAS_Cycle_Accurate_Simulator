## 1. Overview & Architectural Scope

CAS `v3.55.0.0` introduces full standard support for **IEEE Std 1800-2023 §10.10** unpacked array concatenations and replications:
- Unpacked array concatenation syntax `{ ... }` and assignment pattern syntax `'{ ... }`.
- Dynamic array automatic resizing when assigned from an unpacked concatenation or replication expression.
- Element append and prepend operations on dynamic arrays (`{arr, elem}`, `{elem, arr}`).
- Merging and concatenating multiple dynamic arrays (`{arr_a, arr_b}`).
- Recursive flattening: elements of unpacked array concatenations that are themselves arrays have their elements flattened into the resulting array.
- Fixed unpacked array assignment pattern validation: positional element assignments to fixed unpacked arrays `T[N]` require exact match in size; otherwise diagnostic `[CAS-DTINPCIL]` is thrown.
- Module-level dynamic array and unpacked array assignments in procedural blocks (`always_ff`, `always_comb`, `initial`).
- Typedef support for dynamic arrays (`typedef T dyn_t[];`).

## 2. Key Language & Kernel Features

### A. Grammar & Syntax (§10.10)
```systemverilog
target_dynamic_array = { element_or_array_1 , element_or_array_2 , ... };
target_dynamic_array = '{ element_or_array_1 , element_or_array_2 , ... };
target_fixed_array   = '{ val0 , val1 , ... , valN-1 };
```
- Operands may be individual scalar/vector elements or unpacked arrays of compatible base types.
- Array operands within the concatenation are flattened in left-to-right order into the target.

### B. Dynamic Array Automatic Resizing
When assigned to a dynamic array or queue:
- The target container is automatically resized to the total element count of the concatenation.
- All elements are width-cast and signedness-adjusted according to the target array element type.
```systemverilog
arr_merged = {arr_a, arr_b}; // Resized to arr_a.size() + arr_b.size()
arr_merged = {arr_merged, 50}; // Append element 50
arr_merged = {5, arr_merged};  // Prepend element 5
```

### C. Fixed Unpacked Array Arity Diagnostic (`[CAS-DTINPCIL]`)
When an unpacked array concatenation is assigned to a fixed unpacked array of predetermined size $N$, the concatenation element count must match $N$ exactly:
```text
[CAS-DTINPCIL] Concatenation element count (got X) does not match target array size (Y) per IEEE 1800-2023 section 10.10
```
