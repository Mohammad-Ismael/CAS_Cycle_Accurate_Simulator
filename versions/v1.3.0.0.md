# Release v1.3.0.0: Procedural Control-Flow Loops & User-Defined Functions

## 1. Overview & Milestone Scope
This release delivers **v1.3.0.0** of the Cycle Accurate Simulator (CAS), implementing **IEEE Std 1800-2023 Chapters 12.7 (Procedural Loops) and 13.4 (Functions)**. The simulator now supports `for`, `while`, and `repeat` control-flow loops, procedural block statements (`begin ... end`), local variable declarations, and value-returning automatic functions with isolated call frames.

---

## 2. Key Architecture Achievements & Refactorings

### A. Procedural Loop Constructs (§12.7)
- **`ForStatementNode`**:
  - Implemented standard three-part `for (init; cond; step)` execution semantics.
  - Supports initial statement assignment, condition evaluation, and post-body step updates.
- **`WhileStatementNode`**:
  - Executes dynamic evaluation loops testing termination conditions prior to each iteration.
- **`RepeatStatementNode`**:
  - Evaluates count expressions to execute fixed iteration count procedural blocks.

### B. Procedural Block Statements & Local Variables
- **`BlockStatementNode`**:
  - Generalized `begin ... end` blocks into first-class procedural statements, enabling nested blocks inside tasks, processes, and function bodies.
- **`VarDeclStatementNode`**:
  - Added support for procedural local variables (e.g., `integer i;`, `logic [7:0] temp;`) registered into execution scopes dynamically.

### C. Function Definition & Evaluation (§13.4)
- **`FunctionNode` & `FunctionCallNode`**:
  - Added module-level parsing for `function automatic [type] [range] name(inputs)`.
  - Registered functions into elaboration hierarchy maps (`result.function_map`).
- **Call-Frame Execution in `ExprEvaluator`**:
  - Invokes user functions inside expressions by establishing an isolated call scope frame (`scope.fn_name__frame`).
  - Evaluates argument expressions, binds them to input nets, executes the function body, and returns the value assigned to the function identifier.
