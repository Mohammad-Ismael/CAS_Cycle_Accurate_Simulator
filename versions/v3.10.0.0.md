# Release v3.10.0.0: SystemVerilog Assertions (SVA) Sampled Value Functions ($rose, $fell, $stable, $past), Preponed Historical Ring Buffering, and Context Diagnostic '[CAS-DTINPCIL]'

## 1. Overview & Milestone Scope
This release delivers **v3.10.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **36.0%** and implementing full IEEE Std 1800-2023 compliance for:
- **§16.9.3 (SVA Sampled Value Functions)**:
  - `$rose(expr [, [clocking_event]])`: Returns 1-bit logic `1'b1` if the least-significant bit of `expr` transitioned from non-1 (`0`, `x`, `z`) in the previous clocking event's Preponed sample to `1` in the current Preponed sample. Otherwise returns `1'b0`.
  - `$fell(expr [, [clocking_event]])`: Returns 1-bit logic `1'b1` if the least-significant bit of `expr` transitioned from `1` in the previous clocking event's Preponed sample to non-1 (`0`, `x`, `z`) in the current Preponed sample. Otherwise returns `1'b0`.
  - `$stable(expr [, [clocking_event]])`: Returns 1-bit logic `1'b1` if the multi-bit or scalar value of `expr` is identical between the current Preponed sample and the previous clocking event's Preponed sample. Otherwise returns `1'b0`.
  - `$past(expr [, [number_of_ticks] [, [enable_expr]] [, [clocking_event]]])`: Returns the sampled value of `expr` from $N$ clocking ticks in the past (default $N=1$). If the history buffer is shallower than $N$ cycles, returns a 4-state unknown value (`'x`) matching the expression width.
- **§16.9.3 & §4.4 (Preponed Historical Ring Buffering)**:
  - Stratified clock-domain historical ring buffers (`std::unordered_map<size_t, SvaClockEdgeHistory> sva_clock_history`) recording Preponed signal vector snapshots on each clock event.
  - Safe, race-free time slot deduplication ensuring all concurrent assertions clocked by the same signal reference identical history state.
- **§16.9.3 & §21.2.3 (Dynamic Context Restrictions [CAS-DTINPCIL])**:
  - Enforces strict rejection of SVA sampled value functions inside continuous assignments (`assign`) during elaboration and inside persistent `$monitor` argument lists during runtime evaluation with diagnostic `[CAS-DTINPCIL]`.

## 2. Technical Architecture & Implementation Mechanics

### A. Frontend Lexer & AST Nodes (`CAS/include/frontend/lexer.hpp`, `CAS/include/frontend/ast_expr.hpp`)
- Added lexer tokens: `TOKEN_ROSE` (`$rose`), `TOKEN_FELL` (`$fell`), `TOKEN_STABLE` (`$stable`), and `TOKEN_PAST` (`$past`).
- Defined `SysSampledFuncType` enum: `ROSE`, `FELL`, `STABLE`, `PAST`.
- Defined AST expression node:
  ```cpp
  struct SysSampledFuncNode : public ExpressionNode {
      SysSampledFuncType func_type;
      std::string func_name;
      std::unique_ptr<ExpressionNode> expr;
      std::unique_ptr<ExpressionNode> num_cycles_expr;

      SysSampledFuncNode(SysSampledFuncType t, std::string name, std::unique_ptr<ExpressionNode> e, std::unique_ptr<ExpressionNode> cycles = nullptr);
      std::unique_ptr<ExpressionNode> clone() const override;
  };
  ```

### B. Expression Parser (`CAS/src/frontend/parser_expr.cpp`)
- Extended `Parser::parse_primary()` to recognize `$rose`, `$fell`, `$stable`, and `$past` calls.
- Supports parsing target expression `expr` and optional past tick depth `num_cycles_expr`, as well as skipping optional enable and clocking arguments.

### C. Kernel Preponed Historical Ring Buffering (`CAS/include/kernel/scheduler.hpp`, `CAS/src/kernel/scheduler.cpp`)
- Structured clock history:
  ```cpp
  struct SvaClockEdgeHistory {
      uint64_t last_recorded_time = (uint64_t)-1;
      std::deque<std::vector<LogicVal>> snapshots;
  };
  ```
- In `StratifiedScheduler::evaluate_sva_assertions()`:
  - On assertion clock edge triggers, if `ch.last_recorded_time != current_sim_time`, enqueues `preponed_net_values` into `ch.snapshots`.
  - Sets `ExprEvaluator::set_current_clock_history(&ch.snapshots)` and `ExprEvaluator::set_preponed_override(&preponed_net_values)`.

### D. Expression Evaluator (`CAS/include/kernel/expr_evaluator.hpp`, `CAS/src/kernel/expr_evaluator.cpp`)
- Implemented `ExprEvaluator::eval_sampled_func(SysSampledFuncNode* func, const std::string& scope)`:
  - `$past`: Evaluates `func->expr` with `preponed_override` bound to `history[hist_len - 1 - cycles]`. Returns `'x` when `hist_len <= cycles`.
  - `$rose`: Evaluates `val_curr` at `history.back()` and `val_prev` at `history[hist_len - 2]`. Returns `1'b1` when `!prev_is_one && cur_is_one`.
  - `$fell`: Returns `1'b1` when `prev_is_one && !cur_is_one`.
  - `$stable`: Returns `1'b1` when `val_curr == val_prev`.
- Supported nested expressions, binary operators, and bit/part-select slicing (`IndexSelectNode`) under `preponed_override`.

### E. Diagnostic Enforcement (`CAS/src/kernel/elaborator.cpp`, `CAS/src/kernel/evaluator.cpp`)
- Rejects SVA sampled value functions in continuous assignments:
  `[CAS-DTINPCIL] Dynamic type in non-procedural context: SVA sampled value function '$rose' used in continuous assignment per IEEE 1800-2023 section 16.9.3`
- Rejects SVA sampled value functions in persistent monitor sessions:
  `[CAS-DTINPCIL] Dynamic type in non-procedural context: SVA sampled value function '$past' used directly in $monitor per IEEE 1800-2023 section 16.9.3 & 21.2.3`
