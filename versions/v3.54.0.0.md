## 1. Overview & Architectural Scope

CAS `v3.54.0.0` introduces full specification support for **IEEE Std 1800-2023 §20.7** array bound query system functions:
- `$left(a [, dim])` returns the leftmost declared index of the specified dimension (default `dim = 1`).
- `$right(a [, dim])` returns the rightmost declared index of the specified dimension (default `dim = 1`).
- `$low(a [, dim])` returns `min($left, $right)`.
- `$high(a [, dim])` returns `max($left, $right)`.
- `$increment(a [, dim])` returns `1` if `$left >= $right` (descending range, e.g. `[7:0]`); returns `-1` if `$left < $right` (ascending range, e.g. `[0:15]`).
- All bound functions evaluate to 32-bit signed integers (`int`).
- Complete support for introspection across packed bit-vectors, multi-dimensional unpacked arrays, packed structs, user-defined `typedef` declarations, and primitive types with vector ranges (`logic [7:0]`).
- Constant-folding at elaboration time allowing bound functions to size module parameters, localparams, and bit-vector bus bounds.
- Context-sensitive diagnostic enforcement `[CAS-DTINPCIL]` rejecting 0 or $>2$ arguments, rejecting invalid dimension indices (`dim < 1` or `dim > $dimensions(a)`), and rejecting non-array scalar operands.

## 2. Key Language & Kernel Features

### A. Grammar & Syntax (§20.7, Table 20-4, Syntax 20-3)
```systemverilog
$left      ( array_identifier_or_type [ , dimension_expression ] )
$right     ( array_identifier_or_type [ , dimension_expression ] )
$low       ( array_identifier_or_type [ , dimension_expression ] )
$high      ( array_identifier_or_type [ , dimension_expression ] )
$increment ( array_identifier_or_type [ , dimension_expression ] )
```
- First operand: array variable, net, memory, port, or a typedef identifier resolving to an array type.
- Second operand: optional dimension expression (1-based index). If omitted, defaults to dimension `1`.

### B. Bound Semantics for Declared Dimension `[L:R]`
- `$left`: returns $L$.
- `$right`: returns $R$.
- `$low`: returns $\min(L, R)$.
- `$high`: returns $\max(L, R)$.
- `$increment`: returns $1$ if $L \ge R$; returns $-1$ if $L < R$.
- Dynamic arrays and queues return ascending direction ($increment = -1$).
- Unpacked dimensions specified with a single size `arr[N]` (interpreted as `[0:N-1]`) evaluate with `left=0`, `right=N-1`, and `increment=-1`.

### C. Elaboration-Time Constant Folding
Expressions involving bound queries applied to typedefs or statically declared arrays fold to constants during elaboration:
```systemverilog
localparam int H_VAL = $high(byte_desc_t);
localparam int L_VAL = $low(byte_desc_t);
logic [H_VAL-L_VAL:0] sized_vector; // [7:0] -> 8 bits
```

### D. Context Diagnostic Enforcement (`[CAS-DTINPCIL]`)
- Arity validation: Calling any bound function with 0 arguments or $>2$ arguments triggers:
  `[CAS-DTINPCIL] <fname> requires at least one argument per IEEE 1800-2023 section 20.7`
  `[CAS-DTINPCIL] <fname> accepts at most two arguments per IEEE 1800-2023 section 20.7`
- Out-of-bounds dimension index: Calling with `dim < 1` or `dim > total_dimensions` triggers:
  `[CAS-DTINPCIL] Invalid dimension index <dim> for array querying function per IEEE 1800-2023 section 20.7`
- Non-array scalar operand rejection: Calling on a scalar 1-bit variable triggers:
  `[CAS-DTINPCIL] Illegal first argument to array query system function; please pass an array identifier or array data type`
