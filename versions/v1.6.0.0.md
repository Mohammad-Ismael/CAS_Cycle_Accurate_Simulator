# Release v1.6.0.0: Intra-Assignment Timing Controls & Stratified Parity

## 1. Overview & Milestone Scope
This release delivers **v1.6.0.0** of the Cycle Accurate Simulator (CAS), implementing full compliance with:
- **IEEE Std 1800-2023 §10.6.1 (Intra-Assignment Timing Controls)**: Support for non-blocking (`target <= #delay rhs;`) and blocking (`target = #delay rhs;`) intra-assignment timing controls.
- **IEEE Std 1800-2023 §4.4 (Stratified Event Scheduling)**: Precise ordering across Active evaluation, NBA region transport settlement, and Postponed monitor sampling.

---

## 2. Key Architecture Achievements & Refactorings

### A. AST & Parser Integration (§10.6.1)
- **`BlockingAssignNode` & `NonBlockingAssignNode`**:
  - Added native `intra_delay` attribute fields with zero virtual overhead or AST bloat.
- **`Parser::parse_statement()`**:
  - Enhanced assignment production rules to detect and parse `#<delay>` immediately following `=` and `<=` operators.

### B. Dual-Phase Scheduling Pipeline
- **Non-Blocking Intra-Delays**:
  - The RHS expression is evaluated immediately in the current Active region.
  - The calculated value and target slice/net are scheduled into `delayed_nba_queue` indexed by timestamp $(T + \text{delay})$.
  - Thread execution continues immediately in zero simulation time.
  - At timestamp $(T + \text{delay})$, matured updates transfer into `nba_queue` to commit strictly during the NBA region.
- **Blocking Intra-Delays**:
  - The RHS expression is sampled immediately in the current Active region.
  - The thread suspends, and the target commit plus process resumption are scheduled for timestamp $(T + \text{delay})$ via `delayed_blocking_queue`.

### C. Stratified Region Execution Discipline
- Aligned `StratifiedScheduler::run_simulation()` with the IEEE 1800 event stratification hierarchy:
  1. Active thread resumption and blocking updates.
  2. Delta stabilization and continuous propagation.
  3. NBA queue transfer and commitment.
  4. Postponed region sampling (`$monitor` / `$strobe`).
