## 1. Overview & Architectural Scope

CAS `v3.57.0.0` represents the landmark achievement of **100.0% Synopsys VCS Golden Parity**, delivering complete standard support for **IEEE Std 1800-2023 §20.14** in-memory string formatting system functions and tasks:
- **`$sformatf(format_string, [args])`**: System function returning a formatted `string` evaluated sequentially according to standard format specifiers.
- **`$sformat(output_string_var, format_string, [args])`**: System task performing in-place string interpolation and updating the target variable.
- **Format Specifier Support**:
  - `%d`, `%0d`: Decimal integer format with leading zero and space suppression.
  - `%h`, `%0h`, `%x`, `%0x`: Lowercase hexadecimal format with minimum-field zero padding (e.g. `%02h`, `%04h`, `%08h`).
  - `%b`, `%0b`: Binary format with leading zero suppression (`%0b`).
  - `%o`, `%0o`: Octal format.
  - `%s`: String literal, string variable, or packed integral vector interpreted as ASCII characters.
  - `%t`: Formatted simulation time.
  - `%%`: Literal `%` character escape.
- **4-State Unknown Handling**: `x` and `z` bits formatted cleanly across `%b`, `%h`, `%o`, `%d`, `%t`.
- **Target In-Place Mutation**: Modifies local variables, module signals, or class properties without side effects.
- **Context Diagnostics `[CAS-DTINPCIL]`**:
  - Enforces at least 1 argument for `$sformatf`.
  - Enforces at least 2 arguments for `$sformat`.
  - Enforces format argument resolves to a string type.

## 2. Key Language & Kernel Features

### A. Grammar & Syntax (§20.14)
```systemverilog
formatted_str = $sformatf( format_string , [ argument_list ] );
$sformat( target_var , format_string , [ argument_list ] );
```

### B. Format Specifier Evaluation Rules
- `%02h`, `%04h`, `%08h`: Pads with leading zeros up to the specified field width.
- `%0b`: Strips leading zeros down to the first non-zero bit (or `"0"` if the value is zero).
- `%0d`: Decimal representation without leading zeros or spaces.
- `%s`: Resolves string variables directly or unpacks ASCII characters from packed vectors.
- `%t`: Prints current simulation time in precision units.

### C. Diagnostics & Strict Standards Compliance (`[CAS-DTINPCIL]`)
- Arity checks:
  ```text
  [CAS-DTINPCIL] $sformatf requires at least 1 argument per IEEE 1800-2023 section 20.14
  [CAS-DTINPCIL] $sformat requires at least 2 arguments per IEEE 1800-2023 section 20.14
  ```
- Type validation:
  ```text
  [CAS-DTINPCIL] Format argument in $sformatf/$sformat must evaluate to a string type per IEEE 1800-2023 section 20.14
  ```
