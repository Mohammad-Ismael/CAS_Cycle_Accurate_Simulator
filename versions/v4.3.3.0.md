## 1. Release Overview & Scope

CAS `v4.3.3.0` delivers **100.0% compliance across all 180 positive benchmarks in the `sv-tests` generic suite (`tests/generic/**`)**, while maintaining **100.0% (283/283) positive simulation parity**, **100.0% (62/62) positive parsing parity**, and **100.0% (12/12) UVM testbench compliance**, bringing the milestone regression suite to **109/109 passing suites**.

### Key Capabilities Delivered in v4.3.3.0:
- **Whitespace Ingestion in Based Number Literals (IEEE Std 1800-2023 §5.7.1)**:
  - Full lexer support for whitespace between size, apostrophe, base format specifiers, and numeric digits (e.g. `1 'b x`, `32 'd 1`, `32 'o 7`, `32 'h 7`, `' b 0`, `' d 1`).
- **Comprehensive Forward Typedef Declarations (IEEE Std 1800-2023 §6.18, §7.2.2, §7.3.2)**:
  - Support for `typedef struct <name>;`, `typedef union <name>;`, `typedef enum <name>;`, and `typedef <name>;` forward type registrations.
  - Multi-token lookahead buffer (`peek_token_n`) enabling deterministic resolution of forward typedefs versus definitions.
- **Enhanced Typedefs & Data Type Qualifiers**:
  - `rand` and `randc` qualifiers in `struct` and `union` member declarations (§7.2.1, §18.4).
  - Explicit vector base type declarations in `enum` specifications: `typedef enum bit[3:0] { ... } myenum;` (§6.19).
  - Associative array typedefs indexed by wildcard `[*]` and arbitrary data types (`[bit]`, `[bit[31:0]]`, `[string]`, multidimensional types).
- **Nested Classes & Package Scoping (IEEE Std 1800-2023 §8.13, §8.23, §8.26)**:
  - Recursive nested class declarations within class bodies (`class Outer; class Inner; ... endclass endclass`).
  - Scoped nested class type usage in procedural variable declarations (`Container::Inner obj;`).
  - Package-qualified base class inheritance (`extends Pkg::Base`) and interface class implementations (`implements Pkg::Iface`).
  - Package-level `interface class` definitions without incorrect package scope diagnostics.
- **Parameter Types & For-Loop Variable Initialization (§6.15, §12.7.1)**:
  - `parameter type` and `localparam type` declarations inside class bodies.
  - `for` loop initializations supporting optional `var` keyword and mixed data type declarations in the header (`for (var int i = 0, bit b = 1'b1; ...)`).
