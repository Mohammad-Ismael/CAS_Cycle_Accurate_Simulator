## 1. Overview & Architectural Scope

CAS `v3.95.0.0` delivers standard compliance for multidimensional array word copying, multidimensional subarray slicing and assignment, and task/function unpacked array formal arguments:
- **IEEE Std 1800-2023 §7.4.5 Multidimensional Arrays**:
  - Full support for multi-packed and unpacked array word copy (`bit [3:0][7:0] arr_a [1:10]; arr_b[2] = arr_a[1];`) with arbitrary start indices.
  - Linear address offset resolution using raw word storage (`get_raw_word()` / `set_raw_word()`), ensuring correct word access across arbitrary index bounds.
  - Multi-dimensional subarray slicing and copying (`int A[2][3][4], B[2][3][4]; B[1][1] = A[0][2];`) supporting procedural blocking and non-blocking assignments.
- **IEEE Std 1800-2023 §13.4 & §13.5 Task/Function Unpacked Array Ports**:
  - Support for unpacked dimension specifications on task and function formal argument ports (`task fun(int a [2:0]);`).
  - Propagation of formal port unpacked dimensions to task/function AST prototypes and local frames.
  - Argument passing and indexing of unpacked arrays across subroutine calls and returns.
- **Regression Suite `v3_95_0_0_multidim_subarrays_and_subroutine_arrays`**:
  - End-to-end verification of multidimensional array word copying, 3D subarray slicing, and subroutine unpacked array ports, achieving 100% golden parity across both CAS and Verilator.
