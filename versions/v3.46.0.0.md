## 1. Overview & Capabilities
Milestone v3.46.0.0 implements full compliance with IEEE Std 1800-2023 §6.24.2 dynamic casting (`$cast`), delivering polymorphic object downcasting with runtime ancestry verification, enumerated value range membership validation, destination variable protection on failure, and diagnostic verification.

### Key Features Implemented:
1. **Dynamic Casting Forms (§6.24.2)**:
   - **Function Form (`$cast(singular_dest_var, singular_src_expr)`)**: Returns `1` upon successful casting and variable assignment; returns `0` upon type incompatibility, dynamic ancestry mismatch, or enum out-of-range value, leaving the destination variable completely unmodified.
   - **Task Form (`$cast(singular_dest_var, singular_src_expr)`)**: Performs assignment upon successful casting; raises a runtime error and leaves the destination variable unmodified upon failure.

2. **Polymorphic Class Downcasting**:
   - Resolves target and source class types dynamically via class inheritance graphs and inheritance hierarchy walks (`is_instance_of`).
   - Supports casting `null` handle literals and unassigned handles to class variables (setting destination to `null` and returning `1`).
   - Safely rejects downcasting across incompatible class hierarchies without corrupting memory or target handle state.

3. **Enumerated Value Range Membership Validation**:
   - Dynamically inspects candidate integer values against the valid member set declared within the target enum type definition (`EnumType::members`).
   - Valid values within enum range succeed, updating the target enum variable and returning `1`.
   - Out-of-bounds or non-member integers are rejected, leaving the destination enum variable unmodified and returning `0`.

4. **Context Diagnostics & Strict IEEE Restrictions (`[CAS-DTINPCIL]`)**:
   - Validates that the destination argument is a singular lvalue variable (identifiers, member accesses, array indices).
   - Rejects non-variable expressions, literals, constants, and parameters with:
     `[CAS-DTINPCIL] $cast destination argument must be a singular variable per IEEE 1800-2023 section 6.24.2`.
   - Prohibits continuous assignment / net targets (`wire`, `wand`, `wor`, `tri`) with:
     `[CAS-DTINPCIL] $cast destination argument cannot be a net per IEEE 1800-2023 section 6.24.2`.
   - Enforces prohibition of fundamentally incompatible casting types (such as `string` or `real` to class handle or enum) with:
     `[CAS-DTINPCIL] Incompatible data type in $cast dynamic conversion per IEEE 1800-2023 section 6.24.2`.
