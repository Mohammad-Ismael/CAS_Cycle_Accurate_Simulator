## 1. Overview & Architectural Scope

CAS `v3.96.0.0` introduces complete standard support for unpacked array slices, slice equality/inequality, and array locator methods querying the iteration index:
- **IEEE Std 1800-2023 §7.4.3 Operations on Unpacked Arrays**:
  - Full support for unpacked 1D array constant slice assignments (`arr_b[5:3] = arr_a[2:0];`) and indexed part-select slice assignments (`arr_c[4+:3] = arr_a[1+:3];`) across blocking and non-blocking assignments.
  - Multi-element slice extraction and assignment preserving index order and element bitwidths.
- **IEEE Std 1800-2023 §11.4.5 Equality Operators on Unpacked Arrays**:
  - Unpacked array slice comparison (`==` and `!=`) operating element-by-element over slices of matching cardinality.
- **IEEE Std 1800-2023 §7.12.1 & §7.12.3 Array Locator Methods with `item.index`**:
  - Scope binding of `item.index` within `with` clauses of array locator and reduction methods (`arr.find with (item == item.index)`), declaring the index property in the iterator's evaluation frame.
  - Support for returning unpacked queues of matching elements from locator methods (`find`, `find_first`, `find_last`, `find_index`, etc.) directly into destination queues (`q = arr.find with (...)`).
- **Regression Suite `v3_96_0_0_unpacked_slices_and_locator_index`**:
  - Comprehensive end-to-end verification covering constant slices, indexed part-select slices, slice equality/inequality, and locator queue population with `item.index`, achieving 100% golden parity on CAS and Verilator.
