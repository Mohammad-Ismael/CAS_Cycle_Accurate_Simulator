# Release v3.35.0.0: Streaming Concatenation Operators {>> {}} & {<< {}}, Dynamic Slices, Stream Packing and Unpacking Across Bitvectors, Arrays, Queues, LHS Unpack Assignments, and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §11.4.14)

## 1. Overview & Milestone Scope
This release delivers **v3.35.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **71.0%** (`[██████████████████████████████████████░░░░░░░░] 71.0%`) and implementing full IEEE Std 1800-2023 compliance for:
- **§11.4.14 (Streaming Concatenation Operators)**:
  - Right-to-left (`{>> slice_size {stream_expression}}`) and Left-to-right (`{<< slice_size {stream_expression}}`) streaming operators.
  - Slice size specifications supported: type keywords (`byte`, `shortint`, `int`, `longint`, `bit`, `logic`), integer literals, constants, and arbitrary expressions.
  - Default bit-stream slicing (when `slice_size` is omitted) defaulting to 1 bit.
  - Streaming packing: concatenating bitstreams from bitvectors, fixed unpacked arrays, dynamic arrays, queues, and strings into contiguous bit sequences with slice reversal for `<<`.
- **LHS Streaming Unpack Assignments**:
  - Continuous assignments (`assign {>> slice_size {tgt1, tgt2}} = rhs;`).
  - Procedural blocking (`{>> slice_size {tgt1, tgt2}} = rhs;`) and non-blocking (`{>> slice_size {tgt1, tgt2}} <= rhs;`) streaming assignments.
  - Slicing and unpacking bit sequences into target variables, unpacked array words, dynamic arrays, queues, and indexed targets with left-justified packing into fixed targets.
- **Hierarchical Interconnect & Unpacked Array Ports**:
  - Memory-level hierarchical port bindings (`MemoryBinding`) connecting unpacked array ports across module boundaries (`output logic [7:0] unpacked_bytes [0:3]`).
- **Context Diagnostics & Semantic Restrictions (`[CAS-DTINPCIL]`)**:
  - Slice size `<= 0` validation rejected with diagnostic `[CAS-DTINPCIL]`.
  - Non-streamable operand validation rejected with diagnostic `[CAS-DTINPCIL]`.
