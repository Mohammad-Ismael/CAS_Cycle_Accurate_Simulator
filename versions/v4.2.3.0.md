## 1. Release Overview & Scope

CAS `v4.2.3.0` introduces built-in support for the Universal Verification Methodology (`uvm_pkg` & `uvm_macros.svh`), along with IEEE Std 1800-2023 §16 SystemVerilog Assertions immediate/deferred assertions (`assert #0`, `assert final`, `assume`, `expect`), interface-scoped properties (`dif.prop`), and recursive base constructor chaining (`super.new`).

### Key Capabilities Delivered in v4.2.3.0:
- **Built-in Standard SystemVerilog Libraries (`uvm_pkg` & `uvm_macros.svh`)**:
  - `CAS/include/std_sv/uvm_macros.svh`: defines standard UVM reporting macros (` `uvm_info`, ` `uvm_warning`, ` `uvm_error`, ` `uvm_fatal`) and utility macros (` `uvm_component_utils`, ` `uvm_object_utils`).
  - `CAS/include/std_sv/uvm_pkg.sv`: implements `uvm_verbosity` enum, `uvm_object`, `uvm_phase` (with `raise_objection`/`drop_objection`), `uvm_component`, `uvm_env`, `uvm_resource_db#(type T = int)` (with `set` and `read_by_name`), and `run_test()`.
  - Built-in include fallback and embedded package autoload upon `import uvm_pkg::*;` or references to `uvm_*` classes.
- **IEEE Std 1800-2023 §16 SystemVerilog Assertions (SVA) Extensions**:
  - Immediate and deferred assertions: `assert #0` (observed-deferred) and `assert final` (postponed-deferred).
  - Assumption and expectation directives: `assume`, `assume property`, and `expect` statements.
  - Hierarchical and interface-scoped property references (`dif.prop`).
  - Hierarchical sequence clocks with dotted identifiers (`@(posedge dif.clk)`).
- **Core Engine & OOP Fixes**:
  - Out-of-body and derived class constructor chaining: resolved recursive `super.new` lookup by tracking current class scope in `ExprEvaluator` and `Evaluator`.
  - Class member associative array support (`static T m_db[string];`).
  - Static method call resolution in scheduler for class-scoped subroutine calls (`uvm_resource_db#(T)::set(...)`).
  - Compilation-unit variable declarations (`string label = "...";`).
