# Release v3.25.0.0: Array Reduction Methods ('sum', 'product', 'and', 'or', 'xor'), Array Locator Methods ('min', 'max', 'find with (item ...)'), Dynamic Array Slicing ('arr[start:end]'), and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §7.12 & §7.4.6)

## 1. Overview & Milestone Scope
This release delivers **v3.25.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **57.0%** and implementing full IEEE Std 1800-2023 compliance for:
- **§7.12 (Array Reduction and Locator Methods)**:
  - **Array Reduction Methods (§7.12.3)**:
    - Supported built-in methods: `sum()`, `product()`, `and()`, `or()`, `xor()`.
    - Optional `with ( expression )` clause where the iterator item defaults to `item` or an explicitly named variable.
    - Operates across dynamic arrays (`[]`), queues (`[$]`), associative arrays, and unpacked memory arrays.
  - **Array Locator Methods (§7.12.1)**:
    - Supported built-in methods: `min()`, `max()`, `find() with ( expression )`, `find_index() with ( expression )`, `find_first()`, `find_first_index()`, `find_last()`, `find_last_index()`.
    - Returns a queue containing the matching element(s) or index(es).
  - **Dynamic Array & Queue Slicing (§7.4.6)**:
    - Slice selection expression: `arr[start:end]`.
    - Assignment of whole array results, slices, and locator outputs directly into dynamic arrays and queues.
  - **Context Diagnostics & IEEE Semantic Restriction (`[CAS-DTINPCIL]`)**:
    - Prohibits continuous assignment invoking array reduction and locator methods on dynamic arrays, queues, and unpacked arrays:
      ```text
      [CAS-DTINPCIL] Dynamic type in non-procedural context: array method 'arr.method()' used in continuous assignment per IEEE 1800-2023 section 7.12
      ```
