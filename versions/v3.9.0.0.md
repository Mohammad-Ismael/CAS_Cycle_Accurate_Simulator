# Release v3.9.0.0: SystemVerilog Assertions (SVA) Concurrent Assertions, 'property', 'sequence', Implication ('|=>', '|->'), 'disable iff', 'assert property', Stratified Preponed/Observed/Reactive Scheduling, and Diagnostic '[CAS-DTINPCIL]'

## 1. Overview & Milestone Scope
This release delivers **v3.9.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **34.6%** and implementing full IEEE Std 1800-2023 compliance for:
- **§16.7 & §16.12 (Property & Sequence Declarations)**:
  - Declarative properties (`property ... endproperty`) encapsulating temporal specifications, clocking domain bindings (`@(posedge clk)`), and asynchronous reset abort controls (`disable iff`).
  - Declarative linear sequences (`sequence ... endsequence`) supporting cycle delay concatenation (`##N`).
- **§16.12.7 (Implication Operators)**:
  - Non-overlapping implication (`|=>`): Requires that whenever the antecedent matches on the current clock edge, the consequent must match starting on the next clock edge (`##1`).
  - Overlapping implication (`|->`): Requires that whenever the antecedent matches on the current clock edge, the consequent must match starting on the same clock edge.
- **§16.14 (Concurrent Assertion Statements & Action Blocks)**:
  - Concurrent assertion declarations `assert property (property_spec) [pass_statement] [else fail_statement];` at module scope and within procedural blocks.
  - Vacuous success semantics: antecedent mismatch does not execute the pass statement block.
  - Non-vacuous match executes the pass statement block; antecedent match with consequent failure executes the `else` fail statement block.
- **§16.14.1 & §4.4 (Stratified Event Scheduler Integration)**:
  - **Preponed Region**: Signal sampling occurs prior to any delta updates in the current time step, guaranteeing race-free input values for temporal evaluations.
  - **Observed Region**: Evaluates concurrent assertions and implication threads against Preponed samples when clock transitions occur.
  - **Reactive Region**: Dispatches assertion action blocks (`pass_statement` / `else fail_statement`), executing variable updates cleanly without disturbing Active-region clock generation.
- **§16 & §21.2.3 (Dynamic Context Restrictions [CAS-DTINPCIL])**:
  - Enforces strict prohibition against referencing property, sequence, or assertion identifiers in continuous assignments (`assign`) or persistent `$monitor` expressions.

## 2. Technical Architecture & Implementation Mechanics

### A. Frontend Lexer & AST Nodes (`CAS/include/frontend/lexer.hpp`, `CAS/include/frontend/ast_module.hpp`)
- Added lexer tokens: `TOKEN_PROPERTY`, `TOKEN_ENDPROPERTY`, `TOKEN_SEQUENCE`, `TOKEN_ENDSEQUENCE`, `TOKEN_ASSERT`, `TOKEN_IFF`, `TOKEN_OVERLAP_IMP` (`|->`), and `TOKEN_NON_OVERLAP_IMP` (`|=>`).
- Defined AST nodes:
  - `SequenceItem`: encapsulates delay and expression element.
  - `SequenceNode`: stores sequence identifier, clock event, and sequence items.
  - `PropertyNode`: stores property identifier, clock event, `disable iff` condition, implication operator (`ImplicationType`), antecedent, and consequent expressions.
  - `AssertPropertyStatementNode`: encapsulates assertion label, property binding, pass action statements, and fail action statements.
- Extended `ModuleNode` with containers `properties`, `sequences`, and `assertions`.

### B. Module & Statement Parser (`CAS/src/frontend/parser_module.cpp`, `CAS/src/frontend/parser_stmt.cpp`)
- Implemented `parse_property()`: parses clocking header, optional `disable iff`, antecedent, implication operator, and consequent.
- Implemented `parse_sequence()`: parses linear sequence expressions with cycle delays.
- Implemented `parse_assert_property()`: parses assertion header, inlined property or named reference, and optional pass/fail action blocks (`begin ... end` or single statements).

### C. Kernel SVA Modeling & Stratified Scheduler (`CAS/include/common/sva_types.hpp`, `CAS/src/kernel/scheduler.cpp`)
- `SvaAssertionInstance`:
  ```cpp
  struct SvaAssertionInstance {
      std::string label;
      std::string property_name;
      std::string scope;
      EdgeType clock_edge = EdgeType::POSEDGE;
      std::string clock_signal;
      size_t clock_net_id = (size_t)-1;

      ExpressionNode* disable_expr = nullptr;
      ImplicationType imp_type = ImplicationType::NONE;
      ExpressionNode* antecedent = nullptr;
      ExpressionNode* consequent = nullptr;

      std::vector<StatementNode*> pass_statements;
      std::vector<StatementNode*> fail_statements;

      std::vector<SvaThread> threads;
      bool fired_in_time_slot = false;
  };
  ```
- **Preponed Region Sampling**:
  - At the beginning of each simulation time slot before time-wheel event dispatch, `StratifiedScheduler::capture_preponed_samples()` captures a full snapshot of the netlist.
  - `ExprEvaluator` applies `preponed_override` during SVA evaluations so that all signal references read their Preponed values.
- **Observed & Reactive Execution**:
  - `evaluate_sva_assertions()` runs after NBA commits in the delta loop.
  - On clock edge triggers:
    1. Evaluates `disable iff` against Preponed samples; if active, flushes pending threads.
    2. Advances pending implication threads: decrements `remaining_cycles` and checks consequent against Preponed samples.
    3. Evaluates antecedent: on match, schedules a new thread (`remaining_cycles = 1` for `|=>`).
    4. Enters Reactive region: executes `pass_statements` for `MATCHED` threads and `fail_statements` for `FAILED` threads.
- **Event Transition Sensitivity**:
  - `Net::change_counter` tracks actual value modifications across simulation time.
  - `EventWaitTarget::initial_change_counter` ensures procedural event controls (`@(posedge clk)`) only respond to transitions occurring strictly after the wait statement is registered.
