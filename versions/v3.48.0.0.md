## 1. Overview & Capabilities
Milestone v3.48.0.0 implements complete support for IEEE Std 1800-2023 §20.6 and §6.23 type query system function (`$typename`), enabling compile-time and runtime introspection of data types, variables, expressions, and user-defined types (UDTs) returning formatted string descriptions conforming to Synopsys VCS reference output.

### Key Features Implemented:
1. **Type Query System Function Syntax & Evaluation (§20.6)**:
   - Syntax: `$typename(expression_or_data_type)`
   - Returns a `string` representing the resolved data type of the expression or data type identifier.
   - Usable across procedural code, initial/always blocks, continuous assignments, and decision logic.

2. **Primitive Type Resolution**:
   - Accurately resolves basic keywords: `int`, `byte`, `shortint`, `longint`, `integer`, `time`, `real`, `shortreal`, `realtime`, `string`, `chandle`, `void`.
   - Formats bit-vector types with compact vector bounds: `logic[msb:lsb]`, `bit[msb:lsb]`, `reg[msb:lsb]`, or unadorned `logic` / `bit` if 1-bit scalar.

3. **User-Defined Type Formatting with Synopsys VCS Parity**:
   - Formats scoped enumeration types as `enum <scope>::<name>` (e.g. `enum v3_48_0_0_pkg::state_e`).
   - Formats scoped structure types as `struct <scope>::<name>` (e.g. `struct v3_48_0_0_pkg::frame_hdr_s`).
   - Formats class types and object handles as `class <scope>::<name>` (e.g. `class v3_48_0_0_pkg::packet_c`).

4. **Hierarchical & Context Resolution**:
   - Resolves data types of local variables in current execution frames and parent scopes.
   - Resolves netlist signals, module ports, and memory arrays.
   - Resolves member variables within class objects and struct instances.

5. **Context Diagnostics (`[CAS-DTINPCIL]`)**:
   - Enforces exactly one argument per IEEE 1800-2023 §20.6:
     `[CAS-DTINPCIL] $typename requires exactly one argument per IEEE 1800-2023 section 20.6`
   - Rejects unresolvable symbols or invalid data types:
     `[CAS-DTINPCIL] Argument of $typename cannot be statically resolved to a known data type or netlist signal per IEEE 1800-2023 section 20.6: '<symbol>'`
