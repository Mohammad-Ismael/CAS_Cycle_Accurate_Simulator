# Release v3.34.0.0: String Data Type & Built-in Methods (len, putc, getc, toupper, tolower, compare, icompare, substr, atoi, atohex, atooct, atobin, atoreal), In-Place Character Mutation, Relational Comparisons, Subroutine Output Write-Back, and Context Diagnostic '[CAS-DTINPCIL]' (IEEE Std 1800-2023 §6.16)

## 1. Overview & Milestone Scope
This release delivers **v3.34.0.0** of the Cycle Accurate Simulator (CAS), advancing simulator maturity to **69.6%** (`[█████████████████████████████████████░░░░░░░░░] 69.6%`) and implementing full IEEE Std 1800-2023 compliance for:
- **§6.16 (String Data Type & Built-in Methods)**:
  - Dynamic `string` variables initialized to empty string `""` per §6.16.1.
  - Built-in string inquiry and manipulation methods:
    * `str.len()`: Returns character count of string as integer.
    * `str.putc(int i, byte c)`: In-place mutation of character at 0-based index `i`. No-op if index is out of bounds or `c == 0`.
    * `str.getc(int i)`: Returns byte value of character at index `i`, or `0` if out of bounds.
    * `str.toupper()`: Returns uppercase copy of string.
    * `str.tolower()`: Returns lowercase copy of string.
    * `str.compare(string s)`: Lexicographical comparison, returning `< 0`, `0`, or `> 0`.
    * `str.icompare(string s)`: Case-insensitive lexicographical comparison.
    * `str.substr(int i, int j)`: Extracts substring from index `i` to `j` inclusive; returns empty string if invalid.
    * `str.atoi()`: Parses decimal string into 32-bit signed integer with underscore skipping.
    * `str.atohex()`: Parses hexadecimal string into 32-bit signed integer.
    * `str.atooct()`: Parses octal string into 32-bit signed integer.
    * `str.atobin()`: Parses binary string into 32-bit signed integer.
    * `str.atoreal()`: Parses floating-point string into `real` value.
- **Relational Comparisons & Concatenation (§6.16.2 & §6.16.3)**:
  - Lexicographical relational operators (`<`, `<=`, `>`, `>=`, `==`, `!=`, `===`, `!==`) between strings.
  - String concatenation syntax `{str1, str2, ...}` returning unified string value.
- **Subroutine Arguments & Callers**:
  - `string` types in function and task argument lists (`input string`, `output string`, `inout string`) and return types.
  - Output and inout parameter write-back to callers across procedural processes and functions.
- **Context Diagnostics & Semantic Restrictions (`[CAS-DTINPCIL]`)**:
  - Method calls (`len`, `putc`, `substr`, etc.) on non-string operands rejected with diagnostic `[CAS-DTINPCIL]`.
  - Continuous assignments attempting to drive or read `string` variables rejected with diagnostic `[CAS-DTINPCIL]`.
