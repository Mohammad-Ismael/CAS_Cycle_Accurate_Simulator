# Release v1.0.0.0: Modular IEEE 1800-2023 Stratified Scheduling Core

## 1. Milestone Overview
This release establishes the baseline compliance milestone (**v1.0.0.0**) for the Cycle Accurate Simulator (CAS). The core simulation execution engine has been refactored into a modular, decoupled architecture conforming strictly to **IEEE Std 1800-2023 Chapter 4 (Scheduling Semantics)**. Results are verified cycle-by-cycle against Synopsys VCS on EDA Playground.

---

## 2. Key Architecture Achievements & Refactorings

### A. Modular Simulation Architecture
- **`TimeWheel` (`CAS/include/kernel/time_wheel.hpp`)**:
  - Implements the discrete-event future time slot queue using a min-priority queue (`SimEvent`) sorted by timestamp and execution order (§4.4.1).
- **`StratifiedScheduler` (`CAS/include/kernel/scheduler.hpp`, `CAS/src/kernel/scheduler.cpp`)**:
  - Implements the formal IEEE 1800 stratified event loop:
    1. **Active Region (§4.4.2.1)**: Continuous assignments, blocking assignments (`=`), and edge-triggered sequential processes (`always_ff`) evaluate and stage updates.
    2. **NBA Region (§4.4.2.3)**: Nonblocking assignments (`<=`) queued during the Active pass commit updates simultaneously across all registers.
    3. **Combinational Stabilization**: Continuous nets re-evaluate post-NBA updates without re-triggering clocked blocks within the same time tick.
    4. **Postponed Region (§4.4.2.6)**: Read-only sampling for `$monitor` and VCD waveform generation occurs strictly after all delta cycles settle.
- **`Engine` (`CAS/include/engine.hpp`, `CAS/src/engine.cpp`)**:
  - Top-level orchestration facade managing elaborated netlists, memory arrays, and frontend synchronization.
- **`Evaluator` (`CAS/src/kernel/evaluator.cpp`)**:
  - Statement evaluation routes nonblocking assignments and simulation termination (`$finish`) through the scheduler; direct local time advances were completely removed.

### B. Accurate Edge & Transition Semantics (§9.4.2)
- Added `Net::commit_time_slot()` to synchronize `prev_value = value` and clear `modified` flags only at the conclusion of a time slot.
- Clock edge evaluation checks both `modified` and transitional states, preventing static signals from producing false edge events on subsequent time ticks.

### C. Process Synchronization & Clean Termination (§20.2)
- Free-running generator blocks (`always begin #5 clk = ~clk; end`) and stimulus blocks (`initial begin ... end`) advance synchronously on the unified time wheel.
- Calling `$finish` sets `simulation_active = false` and breaks the event loop immediately, cleanly terminating free-running loops without timeouts.
