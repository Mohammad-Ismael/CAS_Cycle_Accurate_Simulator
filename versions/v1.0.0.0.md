# Release v1.0.0.0: IEEE 1800-2023 Stratified Scheduling & NBA Delta Loop

## 1. Overview & Milestone Scope
This release marks the initial compliance milestone (v1.0.0.0) for the Cycle Accurate Simulator (CAS). The core simulation execution engine was refactored from an unsynchronized procedural thread execution model into a unified discrete-event time wheel adhering to **IEEE Std 1800-2023 Chapter 4 (Scheduling Semantics)**. Results are validated against Synopsys VCS on EDA Playground.

---

## 2. Key Architecture Achievements & Fixes

### A. Discrete-Event Time Wheel & Process Synchronization (§4.4.1)
- Refactored `Engine::run()` to advance simulation time strictly using a global `time_wheel` priority queue.
- Concurrent procedural blocks (`initial` and free-running `always begin ... end`) now step synchronously.
- Removed local time jumps inside statement evaluation (`sim_time += delay`), preventing isolated threads from running ahead of global simulation time.

### B. Stratified Delta Cycle Execution (§4.4.2)
- Implemented a two-phase slot convergence loop in `Engine::execute_time_slot_delta_loop()`:
  1. **Active Region (§4.4.2.1):** Combinational signals propagate, blocking assignments (`=`) evaluate, and clock-edge triggered sequential processes (`always_ff`) sample current states.
  2. **NBA Update Region (§4.4.2.3):** Nonblocking assignment values (`<=`) staged in `nba_queue` are committed simultaneously across all registers.
  3. **Combinational Re-propagation:** Combinational logic updates following NBA commits without re-triggering clocked sequential blocks within the same time slot.
  4. **Postponed Region (§4.4.2.6):** Read-only sampling for `$monitor` and VCD waveform emission executes once per time slot after all delta cycles stabilize.

### C. Frontend Parser Improvements
- Corrected classification of plain `always` blocks without sensitivity lists (`always begin ... end`) from `ProcessType::COMBINATIONAL` to `ProcessType::ALWAYS`, ensuring proper rescheduling onto the event wheel.

### D. Clean Engine Termination (§20.2)
- Execution of `$finish` immediately sets `simulation_active = false` and breaks the event dispatch loop, cleanly terminating infinite clock generators without timeouts.

## 3. Verification & Golden Comparison
- **Benchmark:** Multi-stage synchronous shift register (`shift_reg_core`) tested against a race-condition blocking assignment chain.
- **Reference Tool:** Synopsys VCS 2021.09+ on EDA Playground.
- **Results:** 100% character-for-character match on console output, timestamps, and stage-by-stage bit propagation from $T = 0$ to $T = 65\text{ ns}$.
